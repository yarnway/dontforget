# P1 常用筛选

2026-10-27，在用户要求等待接电期间继续其他任务后，完成事项管理中常用筛选的首版。原生跨日样本和冻结应用继续按[原生验收记录](P1_Native_Acceptance_2026-10-27.md)执行；本页开发没有启动该应用或改动其沙箱。

## 修改内容

- 在管理、暂停、回收站、归档、执行记录中，可将当前分类及关键词命名保存；列表显示名称和筛选摘要，一次选择恢复分类与输入内容。
- 支持重命名、删除及撤销；同名、上限或写入失败均明确反馈，失败保留原筛选。最多 12 项，名称长度上限 64，关键词上限 240。
- 事项与执行记录使用一致的标题／项目／标签关键词过滤；查询首尾空白统一处理，保存及重新应用后的结果保持一致。
- 筛选区按可用高度滚动，事项列表保留空间；名称表单在小屏、放大文字和键盘出现时可滚动。中英日文均提供文案。
- 保存于现有 `Settings.workspace_drafts_json` 的独立版本化键 `savedTaskFilters`，维持 schema 16。其他草稿按原键合并，模型设置保存不会覆盖该字段。
- 串行处理筛选编辑，以数据库代次及运行时会话拦截恢复前的旧窗口／撤销。损坏数据保持原样，禁用保存入口并保留手动筛选能力。备份预检校验该命名空间；原来没有筛选的备份仍兼容。
