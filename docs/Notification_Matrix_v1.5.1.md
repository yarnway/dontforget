## 7db822a 发现的缺陷与源码回归

三个独立协议测试先失败，修复后通过：

1. Mac Q3/Q4 的 Darwin 通知未显式关闭声音，插件初始化默认启用声音。
2. 调度等待首次初始化时，后续取消无法阻止旧调度恢复；原生 add 与 cancel
   并发时同样缺少任务级顺序保障。
3. 沉浸/办公情境拦截仍广播到期事件，首页会继续显示到期弹窗；模式切换也未同步
   取消此前已经提交给系统的次要通知。

修复采用任务修订号、任务级原生操作队列、显式 Darwin 声音配置、
低优先级应用内静音、专注模式下的未来原生通知重排及停止广播被拦截的到期事件。
办公情境仍保留事后摘要。Windows 次要通知使用静音 Toast 且不抢窗口焦点；
该 Windows 行为仍需原生设备验证。

新通知回归共 8 项，覆盖初始三个失败、原生添加期间取消、初始化期间连续编辑、
专注开关与完成任务、办公情境摘要和应用内声音。另有既存 3 项初始化顺序测试。
全量 71 项 Flutter 测试和 10 项打包测试通过。

专注/情境策略仍仅在当前会话有效，尚无跨重启持久化或送达确认记录。
拒绝权限与原生调用失败的用户反馈、通知点击路由、跨会话去重仍属于开放项。
