# DontForget v1.8.0 · Android / Windows / Linux

1.8正式版包含Android、Windows x64及Linux x64，build64／schema17。

## 更新

- 精简输入、设置及模型配置页的说明文字；保留简短状态、错误反馈与必要确认，减少界面干扰。
- 设置页支持宽屏并排偏好与双列功能卡片；手机和大字号使用单列，缩放时保留未保存内容。统一卡片间距、图标、标题及保存栏。
- Windows输入框默认单行，多行或长文本自动展开，保留光标、中文组合态与草稿；长内容在框内滚动。
- 普通录音保存为持久附件并提交记录后，释放本次录音的临时副本；写入失败或返回非本次路径时保留文件，减少新录音的重复缓存。
- 内容管理显示可清理及所选文件空间，支持筛选、最多100项批量选择和取消选择。执行前仍需确认，并检查引用、保留备份与使用中材料。
- 新配置默认腾讯实时语音识别中英引擎，保留“按住录音、上滑右侧转文字”。选择转文字后按接口节奏发送已录音频，结果留在可编辑草稿；取消／失败保护原声，旧Flash配置保持兼容。公开包不含个人服务凭据。
- 修复Windows原生WAV文件头兼容问题，两端新语音录音采用16kHz单声道；语音设置说明收进帮助。
- 修正通知队列与发送后草稿测试的真实I/O等待，保留原业务断言，改善Windows回归稳定性。

## 下载与升级

- **Android**：`DontForget_Android_v1.8.0.apk`为通用安装包，Android7／API24及以上，支持ARM32／ARM64／x86_64；AAB用于分发准备，不能直接安装。本轮正式发布不包含独立ARM64包；此前ARM64体积比较属于本地候选，不移记为本包缩小比例。
- **Windows x64**：Setup安装或Portable解压启动，尚无Authenticode签名；业务数据不以Portable解压目录为存储保证。
- **Linux x64**：tar.gz解压后在完整桌面会话运行`./dont_forget`，CI基线Ubuntu24.04，运行库要求见使用指南。
- Android沿用固定发行证书SHA-256：`3db49656984fb848a73b1e8d056846b97e2a7caf47c9a9ae74f475cdbb79e9f1`，已发布发行身份可同签名升级。独立QA47和历史临时签名不自动转换；保留含数据的旧App及备份。
- schema17不变；升级前保留备份和附件。附带三平台清单／摘要、固定源码来源、Windows隔离安装／升级／卸载及Windows／Linux启动报告。

## 已知范围

- 源码、自动化、包与真实设备验收分开记录；本轮没有将渲染预览记作实机截图。Windows原生输入法／多屏／托盘／Toast／物理快捷键、其他Android机型及录音中断、通知休眠重启仍待验。
- 未配置账号时腾讯识别保持关闭。Windows和Pixel原生录音／安全存储及中英合成样本真实识别已通过；真人原手势／草稿编辑、混合语音与其他机型继续验收，后端通过不代表全部原生界面通过。DeepSeek实际任务提取已有结果，AI时间建议仍需复核。
- 带附件真实跨设备恢复、凭据锁定／重新授权、磁盘满／断电和长期保留管理继续。录音优化针对新生成的重复缓存，不自动删除历史附件或用户数据。
- 图片／文件系统分享、LAN编辑／删除／附件／冲突、学习及排程尾项继续开发。Apple签名公证、Windows正式签名和商店分发后续推进。
- 本机事项库与恢复副本没有应用层全库加密，服务密钥不随跨设备备份迁移。
