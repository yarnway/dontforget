# 事项附件与图片预览

内部构建版本：1.7.0+39。更新日期：2026-10-28。

## 使用方式

1. 打开已经创建的提醒事项，进入详情中的“附件”。
2. 选择“添加图片”或“添加文件”。文件会复制到应用自己的存储目录，原文件保持不变。
3. 图片显示缩略图，点击可打开独立预览并缩放；文件可保存副本。任务卡上的附件数量入口可返回详情。
4. 附件变更自动保存；标题、说明等表单编辑仍使用原有保存与未保存提示。移除附件后可撤销，关联的原始输入记录不被替换。

每个事项最多新增 12 个附件，每个不超过 32 MiB。附加资料不会自动发给 AI，也不会改变事项的提醒时刻、通知修订号或已送达的通知。现有语音、图片等原始输入入口继续保留。

## 数据与恢复

- 复用现有 `MediaRecords` 和 `LocalMediaStore`；新增引用放在 `details_json.attachment_ids`。数据库仍为 schema 16，不新增连接或表。
- 文件导入受现有恢复门禁、操作队列及数据代次保护；媒体索引与事项引用在同一事务提交。保存失败只清理本次新复制的私有文件。
- 附件移除仅解除事项引用，保留媒体供撤销及其他引用使用；不删除用户原文件。
- 非空附件引用使用详情格式版本 3。没有新附件的旧数据仍使用原版本 1/2。旧客户端不认识版本 3；降级前应使用升级前快照，不让旧客户端覆盖新格式数据。
- 含媒体的便携备份保留引用与文件，检查阶段会报告缺失的媒体索引。常规路径备份仍不等于附件文件备份。
