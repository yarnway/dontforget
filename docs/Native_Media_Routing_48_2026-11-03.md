## 发现与修复

冷启动深链进入语音详情时，能看到Linked input record，但没有“播放／预览原始记录”按钮。原因是通知、协议和实时活动入口创建TaskDetailScreen时未传入onPlayMedia，首页打开详情则有回调。

本轮通过现有WorkspaceToolsCommand将这些入口委托给首页已有媒体播放流程，复用同一个播放器、路径解析及错误反馈；恢复时先解除回调再停止播放，销毁时只清除自身注册的处理器。原生详情回调绑定导航代次，恢复中、旧代次或App已销毁时拒绝执行。

新增4项回归：协议与通知详情实际按钮委托、恢复／销毁后的旧回调拒绝，以及首页销毁／暂停时解除媒体处理器。22项路由专项通过；最终Flutter全量 **2157通过／20跳过／0失败**（282秒），分析 **0 issues**（53.8秒）。专项计入全量。未修改Python脚本，不重复计上轮136项结果为本轮新运行。

首次并行验证出现超时，新暂停测试的等待也未推进fake时钟；调整测试等待方式并串行复跑通过。原生构建首次在SQLite依赖下载处遇到TLS握手失败，按sqlite3包内固定SHA-256取得同一官方arm64资产并填入标准缓存；没有关闭TLS校验、改依赖或替换版本。构建后续串行执行，失败日志保留。
