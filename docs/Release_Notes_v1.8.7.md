# DontForget v1.8.7 · Android / Windows / Linux

手机语音交互优化与词条档案，build76／schema17。

## 更新

- 手机上滑时显示实时文字；预览区明确区分编辑与发送，继续右滑可选择松手发送。小幅手指抖动时保持选中状态，返回编辑区可解除发送选择。
- 松手编辑后使用贴近键盘的文字面板，底部保留草稿与发送操作；小屏、横屏和大字号自适应。长草稿及中文候选保留，后续识别不会覆盖手动修改。
- 转写预览随主题调整，交互背景按圆角裁剪；编辑面板打开时隐藏重复的背景输入与预览。录后转写路径明确显示“松手后转写”。
- 学习计划与学习管理新增只读词条档案，支持检索词条、释义和例句，展开查看已有复习记录；排期统计共用“未来7天”卡片。
- 更正或删除词条说明后，彻底删除来源与清理完成事项仍保留旧词进度；已有释义继续保留，归档失败整体回滚。
- 无新增依赖或数据库迁移，保留ARM64小包。

## 验收范围

- Android固定签名ARM64 APK／通用APK／AAB、Windows x64 Setup／Portable、Linux x64归档；Windows未做Authenticode签名，Linux基线Ubuntu24.04。
- 源码、自动化、独立设备交互、普通应用升级和发行包分别记录，见[阶段台账](https://github.com/yarnway/dontforget/blob/main/docs/Next_Steps_2026-11-02.md)。合成转写界面验收不代表真实麦克风、云端识别速度或系统IME全部通过。
- 本版不改变语音上传时机：启用腾讯实时识别时，从录音开始上传，取消不能撤回已发送部分。录后识别与实时识别分别显示。
- 档案清除、身份迁移、动态学习预测、图片分享／同步冲突、其他IME与机型、真实通知／录音中断、Windows GUI、恢复故障及Apple签名／商店继续推进。
