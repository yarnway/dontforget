# “别忘了” (Don't Forget) - 分阶段开发推进计划

本项目将按照敏捷开发理念，分四个主要阶段推进，确保高稳定性、高性能及高颜值界面。

## 阶段一：基础设施搭建与纯文本 MVP (Week 1-2)
**目标**：跑通全平台框架、本地数据库、多语言以及大模型的文字处理链路。
1. **工程初始化**：使用 Flutter 创建跨平台工程，配置 Windows/macOS/Linux/Android/iOS 目标。
2. **底层开发**：集成 SQLite/Isar 数据库，设计 `Settings` 和 `Reminders` 表。
3. **本地化机制**：引入中、英、日三语语言包文件。
4. **API 配置 UI**：完成“设置”页面，允许用户填入自定义的大模型 API Key, Base URL 和模型名称 (支持兼容 OpenAI 格式的各类大模型，包括本地自建)。
5. **文字输入与解析**：实现基础文本输入框，调用大模型接口自动解析出时间与事项，保存到本地。

## 阶段二：智能分类与多模态记录 (Week 3-4)
**目标**：实现四象限分类法则，并支持图片、语音等多模态数据的输入。
1. **多模态集成**：
   * 引入录音插件，支持语音转文字 (可通过大模型的音频识别接口如 Whisper，或端侧语音模型)。
   * 引入相机与相册插件，支持拍照和上传截图。
2. **多模态大模型解析**：若用户提供的是图片，则调用具备 Vision 能力的大模型 (如 GPT-4V 或等效接口) 提取画面中的待办事项。
3. **四象限视图开发**：开发美观的 Eisenhower Matrix (艾森豪威尔矩阵) UI 看板，利用大模型返回的 `quadrant` 字段将任务自动渲染在四个区域中。

## 阶段三：本地提醒引擎与性能优化 (Week 5)
**目标**：完成本地调度提醒服务，并优化应用性能。
1. **本地推送集成**：使用 `flutter_local_notifications`，根据大模型提取的时间戳，向系统注册本地定时通知。
2. **分级提醒策略**：
   * 紧急且重要：弹窗 + 强震动 + 高优先级通知。
   * 重要不紧急：常规日历时间点通知。
   * 紧急不重要：静音通知提示。
3. **性能与稳定性**：
   * 图片与视频本地压缩存储，避免 SQLite 爆满 (数据库只存路径，文件存 App 私有目录)。
   * 大模型请求超时处理、重试机制、无网络状态提示。

## 阶段四：UI 极致打磨与交互动画 (Week 6)
**目标**：让应用界面达到商业级标准，“美观好看”。
1. **主题与色彩**：引入柔和的莫兰迪色系或极简黑白灰，适配深色模式。
2. **微交互动画**：列表滑动阻尼效果、完成任务的打勾撒花动画、录音时的声波动画。
3. **打磨排版**：全面检查中、英、日三种语言下的字体渲染和排版是否溢出或不协调。
