# 腾讯云录音转文字、设置精简与稳定性 +56（2026-11-05）

用户明确要修复的入口是“点击输入文字，按住录音后上滑往右转文字”，随后选择腾讯云。+55的单击实时听写方向不符合该入口，不能作为本问题完成依据；本轮撤下该入口和实现，恢复原手势并接入腾讯云录音文件识别。

## 源码与使用方式

1. 点击输入区打开文字键盘；隐藏键盘或切换输入法后再次点击，会显式重开编辑连接。空闲输入区按住录音；输入框已有草稿时，可先点麦克风切到录音模式，原草稿保持。
2. 上滑往左取消；上滑往右选择“转文字”，松开后识别已录制的音频。文字追加到草稿供编辑，仍需明确发送；普通松开保存原声。Android普通保存不上传转写。
3. “设置 → AI服务 → 录音转文字”填写已开通腾讯云语音服务账号的AppID、SecretId和SecretKey，开启并保存。此操作会在选择转文字／重试时上传录音，服务可能收费；无需在聊天中提供凭据。
4. 使用固定腾讯云HTTPS地址及`16k_zh_en`引擎，支持中英文录音的同一配置，不随界面语言切换。应用当前限制单段5分钟、10MiB；不自动重试付费请求。失败时原声保存为可播放备忘，提示配置、鉴权、额度或网络原因。

接入依据：[腾讯云录音文件识别极速版](https://cloud.tencent.com/document/product/1093/52097)。该官方接口接受M4A/AAC等原始音频，使用请求签名。供应商声明的语言能力不等于本轮已通过真实账号的中英文验收。

原始音频采用流式二进制上传，避免整段Base64副本；响应限制2MiB、文字限制32000字符，连接、上传、响应及总请求有界。签名只在内存生成，SecretKey不进入URL；错误只传安全代码，不打印原始HTTP异常、请求签名或音频。禁止跳转到其他目的地。恢复／取消使旧请求和迟到结果失效，不借用聊天密钥或静默调用其他供应商。

三项腾讯云凭据整体写入既有系统安全存储，SQL仅保留凭据引用和无密钥语音元数据；可移植备份清除整个凭据封包。schema继续17，兼容已安装+54／+55数据，不降级或清空。

## 设置与性能／稳定性

- 设置首页只展示语言、外观和发送方式；AI、通知诊断、数据保护、内容管理和同步进入各自次级页面。高级连接表单默认折叠，保留输入和保存／放弃保护。明暗主题、三语、320宽与2倍文字专项验证。
- 打开常用设置及AI页面时不挂载通知权限／诊断观察者，也不初始化LAN服务；相关原生查询和生命周期监听在进入对应页面后才开始。首页不展示密钥表单或本地模型探针。
- 常用偏好只在事务中更新3个非秘密字段，共用凭据写入序列；不读写或轮换安全凭据。比较编辑前偏好，拒绝旧草稿覆盖新值；状态发布与其他设置写入串行，恢复代次变化拒绝旧操作。专项在安全存储读写故障时仍能保存偏好，凭据引用及密钥字节保持。
- +55 CI的Windows磁盘等待导致通知批量测试30秒超时，以及草稿等待500次轮询耗尽。Windows全量门禁与本机统一为并发4、2分钟有界超时；草稿测试按20秒真实截止时间等待SQL完成，不修改业务成功断言。最终CI结果另记，不能据本地通过宣布已修复runner问题。
