# v1.5.2 工作台性能与可靠性迭代

日期：2026-10-21。版本：1.5.2+3，数据库仍为 v8。本轮是独立维护版本，v1.6 的恢复、多模型和持久化提醒闭环继续单独验收。

## 本轮范围

### 数据与状态

- RemindersNotifier 初始化读取、刷新、增删改、链接和优先级扫描进入同一操作队列，避免跨 await 使用旧列表覆盖新任务。
- 修改按调用时请求的字段合并到队列内最新状态，保留同任务的其他并发修改。
- 自动关联与新增、双向链接、批量动态跃迁使用 SQLite 事务；持久化成功后发布状态。重复 ID 拒绝覆盖，失败不阻断后续队列。
- 导入附件使用独立目录保留原名；同名文件与并发导入不覆盖已有附件。复制失败只清理本次未提交目录，保留源文件。

### 浏览与性能

- 工作台先按分类分桶，再构建可见卡片和滚动缓存；完成/滞留分组展开后仍按需构建，任务 ID 保持组件状态。
- 小于 640px 使用分类选择器与单列列表，桌面保留四象限；键盘方向键/Home/End 可切换分类。短高度时选择器使用横向滚动。
- 10 秒提醒补查保留，但不再驱动整个首页重建；时间相关的列表状态每分钟与前台恢复时更新。
- 搜索在任务变化时建立小写字段索引，子任务 JSON 不再逐键重复解析；150ms 防抖，数据变更后结果更新。
- 空闲录音控件没有持续 ticker；录音状态尊重系统减少动态效果。修复长按释放先于原生启动时可能继续录音的问题。

### 操作与视觉

- 48px 完成按钮、显式任务菜单、键盘可操作的子任务折叠；标题、摘要、可换行标签分层显示。
- 完成、删除、撤销和拖动等待持久化结果；失败保留可操作状态并给出简短反馈。
- 搜索文案明确为标题、摘要与子任务检索，补齐中英日操作文案；Ctrl/Cmd+F 与 Esc 支持打开和关闭搜索。
- 缩短本地输入提示，清理与图标重复的 emoji，减少窄屏折行和字体缺字。
- 设置页异步检测增加离页保护；模型官网入口支持桌面打开，在无法打开的平台提供可选择网址和复制入口。
- 详情页保存与删除等待持久化，失败保留页面；删除撤销等待重建完成。
- 详情编辑按打开页面时的基线提取修改字段，合并后台变化；删除后的任务不能由旧页面重新创建。
- 卡片、象限和分类按钮同步主题颜色，移除重复背景动画，避免切换深浅主题时的短暂低对比；发送按钮使用与背景配对的前景色。

## DeepSeek 模型名称校正

按用户追加授权，一并修正配置映射。2026-10-21 核对[官方 API 模型列表](https://api-docs.deepseek.com/api/list-models/)和[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)：API 标识为 `deepseek-flash` 与 `deepseek-v4-pro`，产品版本名不直接当作请求标识。

官方 HTTPS 根地址和 `/v1` 地址上的已知 Flash 别名（含旧 v4、v4.1 和 `DeepSeek-V4.1-Flash-1017`）映射为 `deepseek-flash`；`DeepSeek-V4-Pro-0813` 映射为 `deepseek-v4-pro`，Pro 不改成 Flash。未知模型与第三方网关保留输入，仅请求时归一化，不改写保存的模型名或密钥。

官方旧新闻中的 Pro 下线规划与当前 API 模型列表存在差异，本实现以当前 API 文档为准。验证使用模拟运输层，不调用用户付费服务，不把模拟请求成功写成实际服务商验收。
