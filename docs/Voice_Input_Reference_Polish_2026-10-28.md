# 语音输入参考样式与启动时序优化

日期：2026-10-28，Asia/Shanghai。延续 P1 新界面与真机验收；本轮源码基线 `cb06051`，业务 schema 16。参考用户最新截图的语音浮层几何和交互，不复制聊天背景内容。构建、自动化与真机结果分别登记。

## 修改内容

- 语音浮层使用黑色遮罩、顶部居中绿色录音气泡、短波形和松手提示。底部改成浅弧形大圆面；取消与转文字两条弧带共用圆心，内侧圆头、间隙和曲率一致，标签居中并沿切线轻微倾斜。左侧取消选中为红色，右侧转文字选中为绿色。
- 普通中文右侧显示“滑到这里 转文字”；中英日三语在窄屏和大字体下使用较短标签，完整操作含义仍由无障碍语义提供。减少动态效果时，准备中指示保持静态。
- 显式语音模式的按住区域在 pointer down 即申请录音启动，不再等约 500ms 的长按判定后才开始申请。长按成立前松手或手势取消会丢弃这次临时录音；普通文字输入的单击仍仅进入文字编辑。
- 准备中与录音就绪分开，启动重复请求共享同一次异步操作，桌面麦克风按钮准备时禁用。录音就绪反馈放在原生 start 返回之后，防止提前让用户以为已经可以说话。
- 按用户后续截图进一步修正输入框的垂直居中：复现桌面提示文字相对可见框偏移 4px，改为独立背景／边框容器、相同字重与行高、均分行距；提示和实际文字共用居中区域，左右按钮也与此区域的垂直中心对齐。多行输入仍按原有 4 行上限滚动，保留选择、剪切、粘贴及输入法行为。
- 上滑左侧取消不转写、不生成事项；上滑右侧仍读取完整已保存录音并进入可编辑草稿，必须明确发送。首次权限和原生音频会话初始化仍需时间；这轮自动化不能证明真实语音开头几个字的识别率。
