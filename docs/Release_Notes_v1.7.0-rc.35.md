# DontForget v1.7.0-rc.35

**未发布**：[CI 40543777563](https://github.com/yarnway/dontforget/actions/runs/40543777563) 在筛选编辑器测试中遇到异步数据库写入等待竞态，平台构建未开始。保留此标签和失败记录，修复后继续 [rc.36](Release_Notes_v1.7.0-rc.36.md)，不移动已推送标签。

预发布候选 `1.7.0+35`，数据库保持 schema 16。

- 手动输入用药时刻支持全角冒号，例如 `07：30、19:30` 可预览并保存为两个正确的提醒时刻；模型结果的格式校验保持严格。
- 事项管理加入常用筛选：命名保存、应用、重命名、删除和撤销，重开后保留；小屏、放大文字与中英日文布局有组件回归。
- 备份预览的三语说明与实际支持的 v7–v16 范围保持一致。
- 保留 rc.34 的前台倒计时刷新、到期状态、非遮挡工具面板、学习卡片、圆弧录音与实时活动。

对应功能源码的本地回归已通过：1542 项 Flutter、126 项 Python，静态分析 0 issues。候选 CI、包身份及附件摘要的结果将在发布前独立核验。

当前 Mac 与 iPhone 真机仍为 rc.34。rc.35 尚未安装；普通通知热冷点击、日文软键盘、真实录音手势和灵动岛同步仍有待验项目，旧候选设备结果不转记为本版本全部通过。稳定版尚未发布。

iOS 附件未签名、macOS 未公证、Android 为测试签名；私有开发设备签名与正式分发分别验收。
