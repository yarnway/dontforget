# 事项详情：先查看，再修改

本轮源码候选1.8.6+75／schema17，正式版仍v1.8.5；未提前认定普通安装、运行中升级或正式发布通过。

## 行为

事项卡片、搜索／知识图谱、关联事项、通知和实时活动等现有详情入口均进入只读`TaskDetailScreen`。阅读、复制、查看原文、浏览词卡和预览附件不修改事项；隐藏完成、删除、时间选择、清单切换、关联增删及附件导入／移除。旧`TaskDetailsDialog`也转到同一只读入口。

点击“修改”后，按当前数据代次和恢复令牌核对，再以最新保存内容打开`TaskEditScreen`；返回或保存后保留查看上下文。已删除或恢复前旧代次的查看页不能据此创建新编辑器。明暗主题、中英日文、窄屏、大字及安全边距共用实现，卡片和底部操作宽度对齐。

编辑器保留中文组合态、键盘保存、未保存提示及并发字段合并；未改内容保存直接退出编辑，不写库或重排通知。原生提醒同步失败仍可重试，已提交数据和较新的输入不丢失。补齐按年重复，以及通用／通勤／历史自定义情境值，避免打开旧数据时下拉框失效；已知模式使用本地化名称。

编辑中的附件和关联保留各自即时保存及反馈；返回时的未保存提示针对表单。未把它们标记成一次性表单事务或“放弃全部修改”。
