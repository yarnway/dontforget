# 学习排期概览（阶段49源码候选）

学习计划管理页新增默认收起的“未来7天”。按当前有效词条和复习日期，逐日查看新词、复习词与超量数量；沿用每日／新词上限，今日扣除已学习词量。只读展示，不移动复习日期，不自动反馈或改变通知。

相同词条跨计划去重，进度采用全局最新历史，未学习词取最早有效批次；暂停、完成、归档和回收站不进入待学排期，其已完成历史仍按现有学习队列规则占用今日额度。逾期归入今天；日界使用本地日历构造，跨月不按固定24小时推算。词条未来反复复习取决于实际反馈，本轮不模拟，界面注明范围。

中英日文、窄屏／宽屏及大字号使用同一折叠卡片，背景按圆角裁剪；展开后显示上限和每日明细。前台跨日及恢复前台刷新日期，离开页面取消定时器。损坏的词条进度显示错误状态，不伪装成零负担。
