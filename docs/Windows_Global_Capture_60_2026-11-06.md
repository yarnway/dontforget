# 阶段49：Windows全局快捷记录 +60（2026-11-06）

## 行为与范围

内部候选`1.7.1+60`、schema17。Windows设置提供默认关闭的“全局快捷记录”：应用运行时Ctrl+Alt+Space唤起既有窗口；首页已有文字保持并获得焦点。模态编辑器保持当前位置，不关闭编辑、不读取剪贴板、不自动创建事项、发起AI或发送。录音／转写／发送及数据恢复期间忽略快捷输入。

原生RegisterHotKey使用MOD_NOREPEAT，冲突不抢占；每次重新绑定轮换消息ID和会话nonce，旧排队消息不能唤起新数据会话。设置存在设备独立JSON，不进入业务Settings或导出备份；旧目录迁移会保留它。损坏、高版本、链接和超限文件拒绝覆盖。文件写入与原生注册序列化，保存失败回退原绑定，恢复排空本地写入并解绑；退出先暂停快捷入口。此功能暂只支持Windows，不暗示Linux全局快捷键已实现。

源码包含Win32注册、MethodChannel、设备存储、运行时恢复隔离、首页输入和设置三语提示。自动化覆盖默认关闭、启停持久化、系统冲突、重试、保存失败回退、新旧nonce、恢复排空／解绑失败、旧监听器不能清除新绑定、草稿保留与录音保护、迁移、文件格式拒绝和三语大字窄窗口。
