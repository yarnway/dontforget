# DontForget v1.7.0-rc.36

预发布候选 `1.7.0+36`，数据库保持 schema 16，固定源码 `feb31795ac918dc39019d0d152419704c93ffddb`。

- 手动输入用药时刻支持全角冒号，例如 `07：30、19:30` 可预览并保存为两个正确的提醒时刻；模型结果的格式校验保持严格。
- 事项管理加入常用筛选：命名保存、应用、重命名、删除和撤销，重开后保留；小屏、放大文字与中英日文布局有组件回归。
- 备份预览的三语说明与实际支持的 v7–v16 范围保持一致。
- 保留前台倒计时刷新、到期状态、非遮挡工具面板、学习卡片、圆弧录音与实时活动。

rc.35 在云端测试阶段失败，未发布。rc.36 修正测试对异步保存完成的等待，并加入受控慢写入验证：保存中禁用重复提交，持久化完成后才关闭编辑框。
