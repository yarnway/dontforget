# Android App内中英文实时听写 +55（2026-11-05）

用户已确认采用App内点麦克风直接听写。当前候选使用Android配置的系统语音服务直接监听麦克风，提供中文（普通话）／English (US)选择；中间结果替换本轮草稿内容，最终文字留待编辑和明确发送。无需应用API Key，也未接入微信私有识别引擎。

## 行为与边界

- 点麦克风开始，再点停止完成；原文本、选区之前／之后的文字保留。重复中间结果替换本轮听写片段，不反复追加；有组合态未确认的输入法候选时不启动。
- 取消本轮恢复启动前完整草稿和选区。网络／服务错误、超时或后台中断保留已识别文字；每次识别的session隔离旧回调。发送、附件和原声录音在听写期间互斥，最终文字不自动发送。
- 长按麦克风或“设置 → 语音听写”选择中文／英文，语言偏好仅存本机Android SharedPreferences，不修改聊天配置。使用默认系统服务，可能联网并由该服务处理音频；不承诺无网络中文或中英自动切换，服务不可用时提示并保留草稿。
- “＋ → 原声录音”保留独立保存音频入口；Android原声保存不再对录音文件调用不支持的设备端转写。已存附件／用药录音审核仍受原平台转写能力限制，不能把实时听写结果转记为文件识别通过。
- 编辑器即使仍持有焦点，点输入区域也显式重开键盘，覆盖隐藏键盘或切换输入法后连接未恢复的情况。
- 主线程创建／停止／销毁识别器；首次麦克风权限允许／拒绝、等待授权时取消、60秒识别上限、停止后8秒结果上限均有处理。恢复维护门禁停止听写，失效界面拒收旧文字。
- +54曾在独立QA安装schema17，当前保留该schema和旧安全凭据／备份兼容，移除云服务运行客户端与配置页。兼容元数据不用于实时听写，也不产生网络请求。

实现依据：[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)、[RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent)。平台接口允许服务自行实现支持语言和中间结果，接入接口不等于每台设备已支持中文。
