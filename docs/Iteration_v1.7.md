# v1.7 迭代与验收清单

当前源码候选：`1.7.0+6`，数据库 schema 10，尚未正式发布。以 v1.6 已有恢复、提醒与多模型基础继续迭代；历史未通过的真机验收不会随版本号自动关闭。

## 阶段一：任务查找与浏览（2026-10-25）

完成清单：

- 搜索入口支持空查询浏览全部任务，新增待办、今日到期、逾期、已完成筛选；今日和逾期排除已完成任务。自然日边界取本地日历，不假设每天固定 24 小时。
- 空白分隔的多个关键词可分别命中标题、摘要和子任务，英文不区分大小写；筛选和关键词同时生效。
- 提供默认、到期时间优先和最近创建优先三种排序；相同时间稳定排序，无提醒时间置后。搜索清除保留筛选，一键重置恢复全部条件。
- 搜索结果随保存后的状态、删除、重新载入更新。复用未变化任务的规范化文本，不复用旧任务状态、不保留旧索引链；关闭搜索后释放索引。
- 窄屏控件换行、搜索列表整体可滚动、宽屏限制至 960 逻辑像素，深浅主题使用主题色。中文、英文、日文的双倍字体短窗口无溢出。
- 修复工作台初始快捷键无焦点、搜索已打开时 Ctrl/Cmd+F 未重新聚焦、防抖期间清空按钮不及时出现，以及双倍英文排序标签横向溢出。
- 本地静态分析无问题；完整 **847 项 Flutter 测试、100 项 Python 测试通过**。额外在 `TZ=America/Los_Angeles` 运行 6 项搜索测试，验证春季 23 小时、秋季 25 小时自然日边界；该测试不替代真实 OS DST 通知验收。
- 375/768/1440 宽度、深浅主题共六份组件渲染通过并检查预览；万条结果只构建可见区域附近的卡片。该渲染是 Flutter 测试环境，原生候选验收另行记录。
- 两次独立顺序复测使用相同 100/1,000/10,000 条合成数据、固定创建时间和逐规模 SHA-256；检查全量与增量索引的结果一致性。原始测量及边界见 [性能记录](benchmarks/search-v17-2026-10-25.json)。

万条数据结果（每项预热 10 次、采样 100 次，单位 ms）：

| 操作 | 第一次 p50 / p95 | 第二次 p50 / p95 |
| --- | --- | --- |
| 单条编辑后全量重建 | 7.800 / 10.452 | 7.960 / 10.552 |
| 单条编辑后增量复用 | 3.792 / 4.378 | 3.780 / 4.048 |
| 逐条解析的多词搜索 | 4.615 / 4.738 | 4.671 / 4.769 |
| 索引多词搜索 | 1.801 / 1.856 | 1.793 / 1.858 |

测量仅包含单进程 Dart 搜索 CPU 时间；全量与增量使用相同的新搜索语义。没有把旧版单短语查询与新版多关键词查询直接对比，也没有将此结果用于声称原生首帧、完整冷启动或通知对账提速。

剩余任务：

- 核验本提交的质量及五平台候选 CI；用独立沙箱执行原生搜索、筛选、编辑后刷新和退出重开验收。
- 清理本阶段生成的测试缓存，保留回退材料、测量日志和候选证据；不删除用户数据或共享工具链。

## 后续阶段

1. **日常操作完整性**：补齐任务创建、重复提醒、编辑和失败反馈的端到端流程，逐项处理发现的问题；跨供应商真实降级需第二个可用服务，当前只验收 DeepSeek。
2. **看板与详情易用性**：统一任务、详情和统计页的信息层级、空状态及键盘操作，验证 375/768/1440 宽度、深浅主题和大字体。
3. **统计与大数据性能**：合并统计页重复全表扫描，减少无关重建；用固定合成数据测列表、备份和完整前台启动，分别报告计算时间与原生帧时间。
4. **发布验收与清理**：各平台设备回归、录音/播放和安装升级；真实春秋 DST 通知与取消、相对硬件唤醒读回仍沿用 [v1.6 剩余清单](Iteration_v1.6.md)。客体与镜像已删除，初始化约束解除前不重新创建大体积环境。
