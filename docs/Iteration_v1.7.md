当前源码候选：`1.7.0+8`，数据库 schema 10，尚未正式发布。以 v1.6 已有恢复、提醒与多模型基础继续迭代；历史未通过的真机验收不会随版本号自动关闭。

## 阶段一：任务查找与浏览（2026-10-25）

完成清单：

- 搜索入口支持空查询浏览全部任务，新增待办、今日到期、逾期、已完成筛选；今日和逾期排除已完成任务。自然日边界取本地日历，不假设每天固定 24 小时。
- 空白分隔的多个关键词可分别命中标题、摘要和子任务，英文不区分大小写；筛选和关键词同时生效。
- 提供默认、到期时间优先和最近创建优先三种排序；相同时间稳定排序，无提醒时间置后。搜索清除保留筛选，一键重置恢复全部条件。
- 搜索结果随保存后的状态、删除、重新载入更新。复用未变化任务的规范化文本，不复用旧任务状态、不保留旧索引链；关闭搜索后释放索引。
- 窄屏控件换行、搜索列表整体可滚动、宽屏限制至 960 逻辑像素，深浅主题使用主题色。中文、英文、日文的双倍字体短窗口无溢出。
- 修复工作台初始快捷键无焦点、搜索已打开时 Ctrl/Cmd+F 未重新聚焦、防抖期间清空按钮不及时出现，以及双倍英文排序标签横向溢出。
- 本地静态分析无问题；完整 **847 项 Flutter 测试、100 项 Python 测试通过**。额外在 `TZ=America/Los_Angeles` 运行 6 项搜索测试，验证春季 23 小时、秋季 25 小时自然日边界；该测试不替代真实 OS DST 通知验收。
- 375/768/1440 宽度、深浅主题共六份组件渲染通过并检查预览；万条结果只构建可见区域附近的卡片。该渲染是 Flutter 测试环境，原生候选验收另行记录。
- 两次独立顺序复测使用相同 100/1,000/10,000 条合成数据、固定创建时间和逐规模 SHA-256；检查全量与增量索引的结果一致性。原始测量及边界见 [性能记录](benchmarks/search-v17-2026-10-25.json)。

## 阶段二：统计性能与复盘反馈（2026-10-26）

完成清单：

- 统计按任务列表版本缓存；一次遍历计算总量、完成率与四类数量。报告的已完成/待办标题样本各最多 6 条、每条最多 160 个 Unicode 码点，降低异常长标题成本。报告加载、复制和错误反馈不重复扫描任务。
- 模型报告、本地统计、模型失败后的本地统计使用独立结果类型，来源随结果传递；空白、畸形及只有 reasoning 的回复不再冒充有效报告。
- 模型失败显示本地结果与重试；意外生成失败明确提示，保留之前报告。任务/设置变化会标记报告过期；恢复会话后拒绝旧结果。
- 复制附带来源，等待系统剪贴板完成后再提示成功；失败反馈且可重试。整个请求不通过异常文字暴露配置或服务端响应。
- 看板使用静态统计卡、完成率和分类条形图；去掉持续背景动画，宽屏限宽并排、窄屏纵向滚动，深浅主题统一。空闲页无持续帧回调。
- 静态分析无问题；完整 **868 项 Flutter 测试、100 项 Python 测试通过**，覆盖失败、重试、复制失败、数据变化、恢复隔离，以及 375/768/1440 深浅主题、中英日两倍字号。六份组件预览已检查；它们不替代原生验收。
- 两次独立顺序测量使用相同 100/1,000/10,000 条合成数据和逐规模摘要，20 次预热、200 次采样；原始结果见 [统计 CPU 测量](benchmarks/statistics-v17-2026-10-26.json)。

| 任务数 | 旧五次扫描 p50 / p95（两轮，μs） | 新单次汇总 p50 / p95（两轮，μs） |
| --- | --- | --- |
| 100 | 2 / 32；2 / 21 | 16 / 44；15 / 31 |
| 1,000 | 17 / 19；17 / 18 | 6 / 11；6 / 8 |
| 10,000 | 165 / 186；163 / 175 | 31 / 35；32 / 33 |

新汇总包含旧看板没有的有界标题采样，小规模中存在额外开销与 JIT 影响；万条 p50 降低约 80%–81%。这只是单进程 Dart CPU 测量，不用于声称首帧、原生冷启动或通知对账提速。缓存复用另外由 provider 身份测试验证。

原生验收中发现并修复：优先级检查命令缺少中英日翻译；返回值已变为批量结果，但手动命令仍直接显示对象。现显示实际提升数量，区分已保存但通知未同步与检查失败，异常详情不进入 UI。新增组件回归覆盖三种结果。

本阶段剩余：

- 其他平台设备验收及历史未关闭验收不随组件测试通过而关闭。
