# DontForget v1.8.1 · Android / Windows / Linux

维护更新，build67／schema17。

## 更新

- 配置页增加区块与表单间距，统一卡片圆角裁剪，移除悬停时露出的矩形背景；高级连接展开区不再叠加第二层外框背景，偏好、模型和语音配置一并调整。

- Windows区分普通关闭与安装器确认的升级退出：普通关闭仍隐藏到托盘，升级退出先排空当前草稿，再暂停本地生产者并关闭数据库，再结束进程。
- 合并重复的升级退出请求，避免重复关闭；录音、转写／本地处理、数据恢复或打开其他编辑页面时暂缓自动退出，防止未完成操作被升级打断。准备失败不继续退出，安装器可中止并保留现场。
- 语音、紧凑输入、设置和空间管理沿用1.8，无新增数据库迁移或依赖变化。个人服务凭据不随包分发。

## 安装与验收范围

- Android通用APK／AAB、Windows x64 Setup／Portable和Linux x64归档；Android沿用固定发行证书，Windows尚无Authenticode签名，Linux基线Ubuntu24.04。
- 旧1.8.0进程缺少升级退出消息处理，安装本版前可能仍需从托盘退出；运行中升级的修复应在本版进程启动后复验，不把退出后安装记作运行中通过。
- 原生消息链路的隔离RestartManager测试已通过，真人界面／真实数据及安装器验收另列记录；录音、恢复及编辑中暂缓退出的完整实机矩阵继续。
- 其他机型／输入法、通知休眠重启、Windows托盘／Toast与物理快捷键，带附件跨设备恢复、故障边界和原声压缩，LAN编辑删除附件冲突与学习排程继续。Apple、独立ARM64附件、正式签名及商店后续。
