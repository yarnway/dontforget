# DontForget v1.7.0-rc.34

此版本为预发布候选，版本 `1.7.0+34`、数据库 schema 16，固定产品源码 `23d4a106077d9d59e7e52a1fffd4364564b15bb4`。

- 提醒倒计时和灵动岛入口随时间更新，返回前台立即刷新，到期时切换状态。后台停止计时；只刷新时间相关控件，保留正在编辑的内容。
- 倒计时补齐中文、英文、日文时间单位；未到期但不足一分钟时明确提示，到期瞬间不再显示“0分钟”。
- 纳入已合并的 schema 16 规划与数据管理、用药和出门独立日期、共用通知容量与覆盖状态、天气边界修复。超出当前安排范围的提醒需要应用重新打开后继续补排，不承诺进程关闭后持续运行应用逻辑。
- 保留学习卡片、圆弧录音、非遮挡工具面板、明暗主题和实时活动。语音转文字后仍需明确发送。

本地静态分析、1515 项 Flutter 和 126 项 Python 测试通过。云端七项作业成功：Flutter 1514 通过/1 项平台跳过，Python 125 通过/1 项平台跳过。21 附件、14 份元数据、五平台版本与源码、七包摘要/大小及四项启动/安装记录独立核对。重复 main 构建主动取消，不计为通过。

前一候选 rc.33 已在 iPhone 15 Pro Max 完成灵动岛热、冷点击，系统到期送达与合成通知取消。rc.34 已在同一 iPhone 完成完整签名升级与 schema 14→16 迁移，原有三任务、设置和五媒体的旧字段保持，升级回退快照已核对。未保存时间草稿从“不足1分钟”自动切换为到期状态，放弃修改后原提醒时间保持。Mac rc.34 升级、普通通知热冷点击、软键盘日文及真实录音仍待独立验收；旧版结果不作为本版本全部通过的证明。稳定版尚未发布。

iOS 附件未签名、macOS 未公证、Android 为测试签名；这些构建不代表正式商店分发。
