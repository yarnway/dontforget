# DontForget v1.7.2 · Android / Windows / Linux

本次为Windows输入体验维护更新，包含Android、Windows x64、Linux x64，build61／schema17；Android沿用固定发行证书。macOS／iOS未纳入本次发行。

## 主要更新

- Windows输入框默认紧凑单行，点击即可输入；短文本保持紧凑，超过两行可视内容或长文本粘贴时原位展开。缩短、清空或成功发送后收起，长文本在输入区内滚动，避免遮挡大部分事项列表。
- 展开和窗口缩放保留同一编辑控件、光标、选区及中文输入法组合态；恢复长草稿时自动适配，发送失败保持原文。布局判断避免重复排版整段长文本。
- 调整输入框圆角、底色和三语提示；日期／录音／附件／发送工具栏适配窄窗口与大字号。全局快捷记录继续聚焦已有草稿，不自动发送。
- 新增8项输入组件回归，覆盖组合输入、十万字符粘贴、草稿恢复、失败发送和三语／双倍字号／窄窗口；Android、Linux保持原有输入布局，依赖锁文件与数据库结构不变。

## 下载与升级

- **Android**：安装`DontForget_Android_v1.7.2.apk`，Android7／API24及以上；v1.7.0／v1.7.1发行身份可同签名升级。AAB用于后续商店分发准备，不能直接安装。证书SHA-256：`3db49656984fb848a73b1e8d056846b97e2a7caf47c9a9ae74f475cdbb79e9f1`。
- **Windows x64**：Setup安装或Portable解压启动；未做Authenticode签名。Portable不代表业务数据保存在解压目录。
- **Linux x64**：解压tar.gz，在完整桌面会话运行`./dont_forget`；CI基线为Ubuntu24.04，运行库要求见使用指南。
- schema17不变，更新前保留备份和附件。独立QA47或其他临时签名不自动转换为发行身份，不应直接卸载含数据的旧App。
- 附带三平台清单、摘要、固定源码来源、Windows隔离安装／升级／卸载报告及Windows／Linux启动报告；源码、自动化、安装包和实际设备验收分别记录。

## 已知限制与后续

- 本次Windows输入框已做组件交互、组合态和实际Flutter渲染验证；原生Windows中文输入法、物理快捷键、多屏DPI、托盘与Toast完整交互仍待验，未将组件渲染图作为原生实机截图。退出后快捷键不作为常驻启动服务。
- 腾讯云录音识别继续默认关闭，需自行配置；按用户决定暂缓真实账号中／英／混合识别验收，不分发个人凭据。
- 微信输入法曾出现全系统空白按键区，长期兼容性及其他机型仍需验收。录音通话／焦点竞争、通知延后二次送达和休眠重启矩阵继续。
- Android分享目前只支持文字／链接；图片／文件分享、LAN编辑／删除／附件／冲突展示、学习与排程尾项继续开发。
- 带附件的真实设备恢复、系统凭据锁定／重新授权、磁盘满／断电仍待验。此前容量CI与+60无附件设备往返结果保留原版本归属，不转记为+61实机结果。
- 本机事项库及恢复副本未做应用层全库加密，服务密钥不随跨设备备份迁移。Apple设备／签名公证、Windows正式签名及商店分发另行推进。
