阶段48独立后端验收，使用本机SDK3.47.2、源码38587ed、全新合成SQLite及1 MiB附件。只在新建临时目录上增删当前用户的NTFS拒写ACE，未修改普通应用数据或目录权限；测试完成恢复原SDDL并删除临时目录。[证据](benchmarks/windows-backup-acl-2026-11-13.json)。

## 覆盖

普通／加密各一轮：备份缓存拒绝创建导出目录，实际返回Windows错误5；恢复权限后生成备份并检查附件数量、加密属性和内容。目标目录拒写时，共用目录导出方法实际失败、未遗留partial或改变已有导出；源备份字节、业务全字段和原附件摘要保持。恢复权限后重试，导出文件字节及inspect摘要与源备份一致。

本机显式Flutter验收1项通过，两种备份均完成。初始通用W拒写同时阻断枚举，改为WD／AD；另一轮误把已有普通导出算成新残留，改为逐文件对照原有导出后复验。失败日志保留在本地build/stage100，未修改产品代码来放宽结果。

## 边界

此验收强制调用共用目录导出分支，未操作Windows原生FileSaver／文件选择器GUI，也不是Linux实机权限验收。普通App调用方的临时备份清理由既有策略负责，方法级源文件保持不代表UI失败后保留临时缓存。未模拟真实磁盘满、断电、凭据锁定或Apple安全存储；这些仍待后续真实平台验收。普通Windows／双Android本轮未新建版本或覆盖安装，已发布v1.8.8的升级证据保持原归属。
