# v1.7 发布验收总表

本轮已提交 `1.7.0+33`（`dbebd361ccbaa4a19ebe3914d5be41fc6c0fb68c`）：修复详情页未保存修改与实时活动按钮的一帧状态差。静态分析、1317 Flutter、126 Python 通过；[CI 40487462571](https://github.com/yarnway/dontforget/actions/runs/40487462571) 质量检查通过，平台构建进行中，尚未公开 rc.33。用户要求收尾后暂停，待手动恢复继续。

当前公开候选：**`1.7.0+32 / v1.7.0-rc.32`**，schema 14，产品源码 `2574c962bf381d1baab0142ec1115e745945fa8d`。圆弧录音、转写草稿显式发送、ActivityKit 扩展已实现；静态分析及本地 1316 Flutter、126 Python 通过。**稳定版尚未发布**。+31 发布前补测发现第二触点穿透，已修复到 +32；+31 标签保留、CI 已取消，未公开 Release。

稳定版范围已按用户要求更新：**以 macOS、iOS 验收完成为设备门槛，不要求凑齐其他平台真机**。仍保留各平台构建和分发限制的独立记录。
