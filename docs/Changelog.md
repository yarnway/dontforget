# DontForget (别忘了) - 版本演进与变更日志 (Changelog)

所有关键架构升级与用户功能演进均严格记录于此。

---

## [v1.2.4] - 2026-09-09

### 🌌 视觉与交互动力学
- **慢速流体复位物理**：弹簧回复刚度调整至 `0.016`，阻尼系数调校为 `0.945`。粒子在被推散后如同在太空失重星尘般在宇宙中漂移扩散，随后丝滑、缓慢、悠闲地缓缓凝结复位。
- **双倍深空星光粒子**：深空星光粒子翻倍至 150 颗，韦伯 4 芒光学衍射十字星芒节点扩充至 32 颗，全屏星系层次更显壮阔。

### 🧼 界面极简化重塑
- **彻底移除右上角数量统计**：移除四象限每个区域右上角的数字计数标签，界面回归纯净精致的分类矢量微标（🔥、⭐、⚡、☕），视觉更轻盈。

### 🧠 智能调度革新
- **大模型智能提前量（Lead Time）评估**：
  - Prompt 与解析逻辑深度升级，引入 `event_time`、`lead_time_minutes` 与 `lead_time_desc`；
  - 能够根据事项特征智能评估提前时间：会议提前 15~30 分钟、出行提前 60~120 分钟、截止日前提前 1~3 小时；
  - 任务摘要中自动附加人性化说明，如“开会时间 15:00 (提前15分钟提醒准备入会)”。

## [v1.2.3] - 2026-09-08

### 🚀 3D 全息 AI 粒子系统全面爆发
- **粒子扩充 3 倍（超 620 个空间点云）**：
  - 主梁采用 Astra 宇宙紫向青蓝渐变（195 粒子）；
  - 折双翼注入 DeepSeek 深海夜光蓝与极光翠绿（240 粒子）；
  - 新增双倾角交叉旋转空间天体轨道环（120 粒子）。
- **深空星光与 4 芒光学衍射十字星芒**：高能恒星达峰时自动绽放光学星刺。
- **线束脉冲传输**：邻近节点编织光纤线缆，高能白蓝脉冲光子沿线穿梭传输。
- **鼠标阻尼与流体尾流旋涡**：二阶指数滤波平滑光标位移，鼠标滑过产生流体尾流拖曳。
- **多轴空间缓慢悬浮摆动**：多频率利萨如谐波运算，融合 Yaw/Pitch/Roll 与微幅零重力呼吸起伏。

## [v1.2.2] - 2026-09-08

### 🎨 工业级 UX/UI 重构
- **3D 立体光粒子 LOGO 造型**：光粒子依据原生 LOGO 轮廓点云塑形。
- **鼠标波纹推散物理**：移动释放涟漪扩散环，点击产生强力 3D 冲击波，胡克定律弹性回弹。
- **彻底清除四象限文字提示**：
  - 移除所有“重要且紧急、重要不紧急、紧急不重要、不重要不紧急”文字；
  - 移除全部“Q1、Q2、Q3、Q4”文字代号；
  - 全站切换为纯净的分类微标（🔥、⭐、⚡、☕）与多语言统一的“分类 1 ~ 分类 4”。

## [v1.2.1] - 2026-09-08

### ⚡ 交互细节与多语言隔离
- **通知消息自动退场**：弹窗提示与 SnackBar 默认 3 秒平滑自动消失，不强迫手动点击关闭。
- **多语言严格隔离**：中、英、日三语字典全量核查对齐，数据看板与空状态动态无缝响应。
- **微型呼吸 LED 状态灯**：标题栏旁微型指示灯常驻显示模型状态（就绪/解析中）。
- **历史提示清理**：一键清除所有历史通知。

## [v1.2.0] - 2026-09-07

### 📦 跨版本系统兼容性与持续集成
- **Windows 7/8/10/11 深度兼容**：
  - 自动向 Release 目录内嵌 VC++ 2015-2022 CRT 依赖与 DirectX `d3dcompiler_47.dll`，在没有安装任何运行库的纯净 Windows 7 SP1 下开箱即用。

  - 配置 GitHub Actions 云端 Windows、macOS、Ubuntu 三台编译机自动化打包，推送版本 Tag 即可自动生成全平台 Release。
