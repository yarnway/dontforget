# DontForget v1.8.24 · Android / Windows / Linux / iOS

## 本版更新

- Windows 搜索框、即将提醒、搜索结果和底部录入区沿同一内容宽度对齐。搜索返回和清除按钮随搜索框缩放。
- Windows 最大化、还原或拖动边缘时，首页工具栏、任务和录入区随窗口重新布局。搜索查询与录入草稿在调整尺寸时保留。
- Windows 中文输入法仍在选择候选时，快速录入暂缓发送。候选确认后可用回车保存。
- Windows 全局快捷记录设置写入失败后，「重试」继续执行原先的开启或关闭操作。应用启动读取设置失败时可重新读取。
- 模型密钥输入框在支持的平台上停用输入法个性化学习。DeepSeek 继续提供服务地址和模型预设，云服务凭据由用户在应用设置中管理。
- Android 和 iOS 的语音编辑框只显示编辑区、「发送原语音」和「发送」，去掉外层背景卡片。删除全部文字即可退出。编辑框带有读屏名称及识别未完成时的读屏提示。
- 语音输入「上滑右转」在手指按住期间即刻启动实时语音转文字（Android／iOS 原生端侧 PCM 流式识别、腾讯云实时流式与 Whisper／Flash 渐进式 WAV 快照转写），手指未松开即可边说边看预览并继续右滑直接发送，不再等待松手后才开始转写。
- 标记事项完成、删除事项（含单条删除、多选批量删除、清空已完成）、删除常用筛选及附件等操作提示均支持 5 秒内点击「撤销」，到期自动收起；系统提醒同步失败等需处理的告警仍保持显示。周期事项完成时会显示下次提醒时间。
- 优化已完成事项管理体验：首页新增「已完成」筛选视图并按完成时间倒序排列，已完成卡片显示完成时间并提供一键删除按钮；在首页、搜索「已完成」筛选、四象限看板与命令面板支持多选批量删除、批量标为未完成及一键清空已完成（均移入回收站并支持 5 秒内撤销）。
- 综合提升可用性、易用性、美观性与稳定性：接入情境模式切换（办公／居家／通勤等）即时触发提醒；修复动态规划短空闲窗崩溃、多智能体象限越界、局域网同步完成记录元数据丢失及偏好保存重试覆盖草稿等问题；补齐中英日口语化时间解析（「三点二十」「一刻」「半小时后」「中午1点」）、全场景 IME 拼音／假名组合态防误触、只读页面无阻塞升级退出与模块化拆分。
- 移动端录音浮层到语音编辑框之间平滑衔接，进入、退出和键盘避让使用缓动，跟随系统的减少动态效果设置。
- iOS 系统分享入口可保存文字、链接、图片和 PDF 为待编辑草稿。局域网权限提示说明同步用途。
- 点击分享草稿中的图片或 PDF 可直接打开。PDF 可在系统阅读器继续翻页，覆盖升级后也能打开旧草稿的原有附件。
- 原语音播放完成后，播放提示自动收起。仍可手动停止或再次播放。

## 下载与安装

- Windows x64 提供安装器与便携 ZIP。安装器未做 Authenticode 签名。
- Linux x64 提供 TAR.GZ 文件，构建基线为 Ubuntu 24.04。
- Android 提供 ARM64 APK、通用 APK 和 AAB，沿用固定发行证书。
- iOS 提供未签名 IPA，需要用 AltStore 个人重签。免费账户通常每 7天 续期。安装步骤见 [Windows 上的 iOS 安装说明](https://github.com/yarnway/dontforget/blob/main/docs/iOS_Sideload_Windows.md)。App Store 和 TestFlight 分发不在本版范围内。
