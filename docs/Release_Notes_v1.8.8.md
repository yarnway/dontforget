# DontForget v1.8.8 · Android / Windows / Linux

语音预览兼容性与保留档案清理，build77／schema17。

## 更新

- 手机录音预览使用独立遮罩，保留状态、转写文字及编辑／发送选择的无障碍节点，屏蔽背景操作；松手、移除输入栏或切换页面时清理遮罩。
- 手势选择与转写反馈分别更新，滑回原声区域可在当前帧恢复提示；保留原有长按、上滑预览、右侧编辑／发送和左侧取消交互。
- 词条档案增加“清理保留记录”：按词条预览，单次最多200条，明确确认后清理无引用的过往标准保留行。当前事项、词条进度、今日学习额度、关联和附件保持。
- 非标准历史标记继续作为词条引用来源；数据变更、跨日或恢复后要求重新预览，清理失败整批回滚。
- 保留ARM64小包，无新依赖或数据库迁移；语音服务与上传时机保持。

## 验收范围

- Android固定签名ARM64 APK／通用APK／AAB、Windows x64 Setup／Portable、Linux x64归档。Windows未做Authenticode签名，Linux基线Ubuntu24.04；Apple签名与设备验收继续推进。
- 源码、自动化、私有合成实机、普通应用升级和发行包分别记录，见[阶段台账](https://github.com/yarnway/dontforget/blob/main/docs/Next_Steps_2026-11-02.md)。原生语义节点读回不等于完整TalkBack操作通过；合成转写不替代真人中英文识别与延迟验证。
- 启用腾讯实时识别后仍从录音开始上传，取消不能撤回此前已上传部分。档案清理不重置受保护词条，也不执行数据库物理压缩或原声删除。
