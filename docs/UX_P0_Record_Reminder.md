# P0 记录与提醒体验集成

日期：2026-10-27。工作分支：`codex/p0-record-reminder`。本轮以 `4c586fa` 为已提交基线，整合初轮 P0 与并行记录功能的一致快照 `329c82c`（仅相关源码和测试），并在本工作树补齐迁移、恢复和交互。主工作区仍有并行编辑，本轮未覆盖其文件、设备数据或发布资产。

## 已实现的体验

- **持久化记录草稿**：文字、时间选择和稳定记录 ID 保存在本机数据库；重启不自动发送请求。提交前保留待处理副本，保存期间继续输入会使用新的 ID，失败或中断后可查看、复制、丢弃或追加恢复到现有输入。原文空白与换行保留；输入法选词期间不提交或覆盖内容。
- **先保存再整理**：先保存原文和用户明确选择的提醒，再异步请求 AI。模型失败保留原记录，显式重试不重复创建；恢复数据后的旧代次不能继续写入。目标和学习计划草稿也沿用本地草稿列与恢复门禁。
- **事项截止时间与提醒时间分开**：两者分别保存、显示和编辑，延后提醒不移动截止时间，循环事项保留各自日期锚点。“提醒时间已过”只描述提醒，卡片另行标识“事项截止时间已过”。搜索筛选仍按提醒时间；今日工作区分别纳入截止事项与应提醒事项。
- **AI 建议显式确认**：文本整理结果作为提案保存在原记录中，可在“查看 AI 建议”中编辑标题、说明、截止时间及提醒时间，勾选事项后确认。取消保留原记录和提案；确认才原子写入所有所选事项并安排提醒。预览期间出现其他编辑时拒绝旧提案，第二项插入失败时整批回滚。图片、文件、视频及语音解析的 AI 时间同样先保留为提案。用户明确输入或选择的本地提醒可以直接保存。
- **清楚的时间与通知状态**：“下一个 20:00”按本地日历计算；AI、手动和未知来源分别标记。详情按需查询已保存轮次、通知日志和系统权限；`submitted` 仅说明请求已提交系统，不证明送达。未保存的提醒设置不套用旧轮次状态。
- **日常处理**：今日、未来、全部和分类视图，最多三项今日重点，更多延后时间与跳过本次周期。CSV 在原 16 列后增加独立的本地事项截止时间列；既有列位置保持，依赖固定列数的下游工具需适配。

## 数据库与备份兼容方案

统一目标为 **schema 15**，保留原有三张业务表和所有已有数据。

| 来源 | 识别与升级 |
| --- | --- |
| schema 7–13 | 按历史迁移补齐字段，原提醒的时间来源保持未知，未设置截止时间的旧记录不编造日期。 |
| schema 14：提醒来源分支 | 完整字段集合包含 `trigger_time_origin`，不包含记录草稿字段；升级时补齐记录、提案与草稿字段。 |
| schema 14：记录功能分支 | 完整字段集合包含 `workspace_drafts_json`、事项时间、建议时间、原文、待整理和重点字段；识别有无 `capture_proposal_json`、`word_progress_json` 的已知变体，保留已有值并补齐缺少字段与来源。 |
| schema 15 | 使用统一完整结构；JSON 和 SQLite 备份采用相同字段与嵌套数据检查。 |

- schema 14 按实际结构识别，不能仅凭 `user_version` 判定。不完整混合结构、未知字段、错误的新增字段类型或默认值会拒绝升级；迁移事务失败保持原库版本和内容。
- 升级前创建带 SHA-256 和来源版本的逻辑快照，失败中止升级；恢复预检支持 v7–v15，继续检查文件活动、大小、行数、未知对象、重复 ID、嵌套 JSON 和引用。备份预检只读源文件，恢复在候选库上迁移和校验后替换，并沿用已有回退协议。
- 同时保留两种历史 v14 固定夹具；v15 有独立固定夹具。`word_progress_json` 的兼容保留不代表本分支已经完成逐词学习功能。
- 回退到旧程序必须使用对应旧版本数据库或升级前快照；旧程序不能直接使用 schema 15。

## 验证证据

使用 Flutter 3.44.9 / Dart 3.12.2：完整 Flutter 回归 **1,309 项通过，0 失败**；Python 脚本测试 **124 项通过**；`flutter analyze --no-pub` 无问题。另在 `TZ=America/Los_Angeles` 下通过本地日历边界测试，此证据不代表真实 DST 通知送达。

专项测试覆盖历史库升级、已知 v14 变体、JSON/SQLite 恢复与源文件不变、无事项备份识别、错误结构拒绝、持久化草稿、失败重开、保存期间继续输入、AI 提案取消/确认/并发编辑与事务回滚、媒体提案、周期日期、CSV 截止时间，以及中英日在 375/768/1440 宽度和大字号下的组件布局。

自动化使用独立临时目录和通知替身，未读写用户数据库。本轮未完成真实设备通知送达、真实进程强制退出、各平台打包、签名、CI 或发布验收；组件与数据库测试不能替代这些证据。
