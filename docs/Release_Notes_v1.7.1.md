# DontForget v1.7.1 · Android / Windows / Linux

本次更新包含Android、Windows x64、Linux x64，build60／schema17；沿用v1.7.0固定Android发行证书。macOS／iOS未纳入本次发行。

## 主要更新

- 修复Android完整备份恢复失败：适配SQLite正常关闭后留下的TRUNCATE空日志，自建候选库通过SQLite规范关闭；非空日志、WAL和不安全链接继续阻止替换，不删除未知日志。Pixel真实加密文件经Windows隔离后端恢复、追加合成记录、返回手机确认恢复及冷重开通过，本轮跨设备样本不含附件。
- Windows新增默认关闭的“全局快捷记录”：应用运行时Ctrl+Alt+Space唤起窗口，首页输入保留已有草稿并获得焦点；编辑弹窗保持，录音／发送／数据恢复时不插入或发送。快捷键冲突可重试，设置独立于业务备份，恢复期间解绑并拒绝旧消息。
- 完成Windows／Linux四份512MiB、总2GiB加密备份专项：加密往返、全部附件摘要、错误密码、取消清理、数据库恢复及重开分别留证。该容量结果使用独立固定源码CI，不代表手机2GiB保存或所有故障场景已验。
- 补充Pixel发行签名同包升级、字段保持、中文候选／软件发送、输入法切换草稿保留、真实麦克风取消及Home中断检查；修正备份支持版本提示。设置保持常用偏好与高级功能分层。
- 发布准备改为按当前版本读取并检查发行说明，缺失或版本不符会停止，不沿用历史正文。

## 下载与升级

- **Android**：安装`DontForget_Android_v1.7.1.apk`，Android7／API24及以上；v1.7.0发行身份可同签名升级。AAB用于后续商店分发准备，不能直接安装，不宣称已经上架。证书SHA-256：`3db49656984fb848a73b1e8d056846b97e2a7caf47c9a9ae74f475cdbb79e9f1`。
- **Windows x64**：Setup安装或Portable解压启动。未做Authenticode签名；Portable不代表业务数据保存在解压目录。
- **Linux x64**：解压tar.gz，在完整桌面会话运行`./dont_forget`。CI使用Ubuntu24.04，GTK3、libsecret、AppIndicator和GStreamer运行库要求延续现有指南。
- 数据库仍为schema17。更新前保留备份及附件；历史临时测试签名、独立QA47不自动转换为发行身份，不应直接卸载含数据的旧App。
- 附带三平台清单、摘要、固定源码来源、Windows隔离安装／升级／卸载报告和Windows／Linux启动报告；源码、包与实际设备验收分别记录。

## 已知限制与后续

- 用户本轮决定暂缓腾讯云真实账号验收；该服务仍为默认关闭、需自行配置的预览能力，中文／英文／混合识别未完成真实账号验收。此次不填写或分发任何个人凭据，不把输入法语音能力计作腾讯云通过。
- 微信输入法曾出现全系统空白按键区，重启服务可暂时恢复；+60屏幕点按中文候选、键盘收起／重开以及Gboard英文和切换草稿保持已有实测，但长期兼容性和真人复测仍继续。测试中的ADB按键注入可能影响输入法状态，不能把相关现象直接当作所有用户必现。
- Windows全局快捷键已有实际OS注册／冲突／释放与草稿隔离测试；物理快捷键激活、窗口／托盘／Toast完整交互仍待原生UI验收。应用退出后快捷键不作为常驻启动服务。
- Android系统分享目前只支持文字／链接；图片／附件分享、LAN编辑／删除／附件／冲突展示、学习和排程尾项继续开发。
- 录音通话／焦点竞争、通知延后二次送达和休眠重启、带附件的真实设备恢复、系统凭据锁定／重新授权、磁盘满／断电等仍待验。Windows真实旧库已完成一次16→17升级及原字段保持，不等于所有历史库都已验收。
- 事项数据库和本机恢复副本未做应用层全库加密；服务密钥不随跨设备备份迁移。Apple设备／签名公证、Windows正式签名和商店分发另行推进。
