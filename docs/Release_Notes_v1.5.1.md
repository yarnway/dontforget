## 本次修订

- 到期提示使用页面内提醒区，提前五分钟安静显示；不遮挡输入，不自动弹模态框、不抢焦点、不重复播放应用提示音。首次到期通过当前任务状态补检，回到前台立即复核。
- 普通反馈移出底部浮层，短时状态自动收起；删除后的撤销保留至处理。无 AI 配置时直接保存本地事项，不反复提示 API Key 错误、不虚构提醒时间。
- 官方 DeepSeek 地址下兼容已知 Flash 别名，鉴权和配置错误不重复请求；服务失败使用简短中文反馈，不展示原始响应和请求编号。用户数据继续保留，可在详情设置提醒时间。
- 修正原声录音关联、启动媒体加载与卡片点击；设置保存/备份操作固定在底部。保存失败保持页面，损坏主库不静默用旧镜像覆盖。
- 首页简化工具入口、折叠已完成事项，窄屏使用单列布局。

## 下载与限制

| 平台 | 文件 | 当前边界 |
| --- | --- | --- |
| Windows x64 | Setup EXE / Portable ZIP | CI 安装与启动通过；真实主机通知、录音和旧库升级待验收 |
| Android | test-signed APK / AAB | APK 可用于设备测试；测试签名，非商店正式包 |
| macOS | unnotarized ZIP | 当前 Mac 核心用例通过；本地签名完整性通过，未公证 |
| iOS | unsigned IPA | 未签名，不能直接安装到 iPhone |
| Linux x64 | tar.gz | CI 虚拟显示启动通过，真实桌面功能待验收 |

七包、五份 manifest、五份 SHA256SUMS、三份桌面启动和一份 Windows 安装报告，共 21 文件。每个包的摘要见对应 SHA256SUMS 与 manifest。未上传用户数据库、密钥、录音或私有验收日志。
