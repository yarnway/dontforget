# DontForget v1.5.1 验收候选

版本 `1.5.1+2`，数据库 v8；候选源码 `23c8c0174e9022332e864ce5c6464edb6c4c9ac0`。
当前保持 draft / prerelease，未公开发布，完整设备验收尚未完成。

## 修订内容

- 移除旧内置 API 凭据，默认密钥为空；升级只清理已知旧内置密钥，保留用户配置。
- 设置保存等待初始化并使用事务，失败保留页面；服务商来源变化时清空旧密钥。
- 备份读取一致事务数据、检查镜像完整性后替换；损坏主库不再被旧镜像静默覆盖。
- 修复月末/闰年循环、错过周期及可空字段清除；原始日历锚点留待 v1.6。
- 修复首次 Mac 录音目录未创建；没有 AI 密钥时保留关联原声任务。
- 首次有效提醒等待通知插件初始化，等待取消完成后重建；完整提醒闭环仍待后续版本。
- 恢复启动时读取媒体索引及界面订阅，提供缺失媒体和播放失败反馈。
- 将卡片长按拖拽阈值从 160 毫秒恢复为 500 毫秒，播放入口扩大为具名按钮，避免普通点击被拖拽抢占。
- 修复原生插件与运行库兼容，五平台统一版本、提交身份及哈希检查。

- 七个交付包本地独立版本、提交身份及 SHA-256 校验通过；草稿仅含对应的 21 个交付与验证附件。
- Windows / macOS / Linux 归档启动检查通过；Windows CI 安装、同候选覆盖、卸载及合成历史文件保留通过。
- 当前 Mac 的首页原录音回放、正常退出重启后回放由用户确认通过，原生音频输出日志与包身份一致。
- 当前 Mac 手动备份成功：主库、镜像、JSON 的设置/媒体/任务三表全字段一致（1/1/3），两库 integrity_check=ok、schema=8，原录音哈希未变。
- 7cdf85b 的录音及停止、应用退出后单次通知横幅和声音通过单独保留；未声称这些场景全部在当前包重跑。当前 23c8c01 的编辑改期、完成、清除时间已完成真实 Mac UI/数据库/系统日志有界验收：22:30 原时点无投递记录，22:32 仅改期通知投递，系统记录横幅及提示音；无本轮用户目视/听感确认。重启后字段保持，测试任务已收尾。

重启发现：系统已送达但尚未完成的任务仍会触发应用内补提醒；跨会话送达确认与去重尚未闭环，列入 v1.6。

## 下载选择与限制

| 平台 | 文件 | 限制 |
| --- | --- | --- |
| Windows x64 | Setup EXE / Portable ZIP | 用户主机实际录音、通知及升级待验收 |
| Android | test-signed APK / AAB | 手机安装用 APK；测试签名，不是正式商店包 |
| macOS | unnotarized ZIP | 未公证，正式分发资格未完成 |
| iOS | unsigned IPA | 未签名，不能直接安装到 iPhone |
| Linux x64 | tar.gz | 虚拟显示 CI 启动通过，实际桌面功能待验收 |

附件为七个包、五份 manifest、五份 SHA256SUMS、三份桌面启动及一份 Windows 安装检查，共 21 个文件。未包含本地测试录音、数据库或设备私有验收数据。
