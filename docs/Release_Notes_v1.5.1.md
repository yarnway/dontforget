# DontForget v1.5.1 验收候选

版本 `1.5.1+2`，数据库 v8；候选源码 `7db822a0055d02dd96f927451830cc125966d7d5`。
保持 draft / prerelease，未公开发布，完整设备验收尚未完成。

## 界面与易用性

- 首页精简为搜索、情境、更多功能与设置；原有图谱、专注、复习、导出、统计和清理入口集中到“更多功能”。
- 使用静态背景、统一留白和柔和分类色；小于 640 宽度使用单列滚动，宽窗口保留四象限。
- 已完成任务默认折叠，展开后继续查看详情和回放；完成任务隐藏紧急跃迁标记，提高文字对比度。
- 设置页限制表单宽度，保存与备份按钮固定在底部，无需滚动至长表单末尾。
- 修正输入框焦点与全局快捷键冲突；“就绪”状态不再暗示 AI 服务已验证连通。

## 稳定性修订

- 移除旧内置 API 凭据；默认密钥为空，升级保留用户自配凭据。
- 设置事务保存、失败留页；备份一致读取并检查镜像完整性，损坏主库不再被旧镜像静默覆盖。
- 修复月末/闰年循环、错过周期及可空字段清除；原始日历锚点仍待 v1.6。
- 修复 Mac 录音目录创建、无密钥原声任务关联及启动媒体加载，提供缺失媒体和播放失败反馈。
- 卡片长按拖拽阈值为 500 毫秒，普通点击使用独立播放入口。
- 首次有效提醒等待插件初始化，等待取消完成后重建；五平台统一版本、提交身份与哈希检查。

## 下载选择与限制

| 平台 | 文件 | 限制 |
| --- | --- | --- |
| Windows x64 | Setup EXE / Portable ZIP | 用户主机录音、通知及真实升级待验收 |
| Android | test-signed APK / AAB | 手机安装用 APK；测试签名，非正式商店包 |
| macOS | unnotarized ZIP | 未公证，正式分发资格未完成 |
| iOS | unsigned IPA | 未签名，不能直接安装到 iPhone |
| Linux x64 | tar.gz | CI 虚拟显示启动通过，实际桌面功能待验收 |

附件为七个包、五份 manifest、五份 SHA256SUMS、三份桌面启动及一份 Windows 安装检查，共 21 个文件。未包含设备录音、数据库或私有验收数据。

## 剩余任务

当前候选完整通知矩阵、休眠/时区、拒绝麦克风权限、磁盘满/中断等失败场景、真实 v7 脱敏样本升级、Windows/Android 实机、iOS 签名安装、正式签名/公证；历史泄露凭据仍需维护者在服务商控制台撤销。

升级前保留数据库与附件副本。备份未加密，包含设置（包括 API Key）和附件路径，**不包含附件文件本体**。不要为绕过 Android 签名冲突卸载有数据的版本；不能假定旧程序兼容 v8 数据库。

v1.6 数据恢复预览、失败回退及提醒闭环尚未开始。完整记录见[发布前验收台账](https://github.com/yarnway/dontforget/blob/main/docs/Release_Acceptance_v1.5.1.md)。
