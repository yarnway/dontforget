# 首页排版与信息精简

日期：2026-10-28，Asia/Shanghai。延续[语音与输入框阶段](Voice_Input_Reference_Polish_2026-10-28.md)，本阶段按用户补充截图调整首页到期操作区，并整理整页信息层级。不是数据库或通知调度规则改造；新界面须使用新的固定源码、构建与原生结果。

## 修改内容

- 到期提醒的稍后提醒、更多延后、完成与确认使用同一套按钮间距、字重和行高；各语言／字号根据实际可用宽度统一计算按钮高度，标签保持垂直居中。更多延后改用相同的 TextButton 和下拉标识，通过 MenuAnchor 展开既有延后选项。
- 通知区、筛选、事项列表与输入栏统一使用 1040 的内容宽度；手机保留紧凑边距。到期按钮在窄屏按行换行并保持一致间距，不强制把大字体挤在一行。
- 事项卡片改用较轻的背景层与中性边框；优先级以色点和状态文字表达。信息标签去掉重复边框，标题与两侧控件垂直对齐。
- 与标题相同的摘要不再重复显示；只做展示去重，原摘要、原文与附件仍保存在详情。截止时间和提醒时间为同一时刻时合并为“截止与提醒”，减少重复日期与过期标识；不同时间继续分别展示。
- 微习惯默认收起、保留数量与展开入口；新执行拆解成功后自动展开结果。重复出现在卡片上的“5分钟微习惯拆解”移到事项菜单，处理期间才显示进度。复习、附件、清单、AI 建议确认、保存失败与撤销入口继续可达。
- 精简“今天暂无安排”和即将提醒的重复解释。必要的异常提示、提醒状态和用户操作反馈继续展示，不把应用内提示当作系统送达。
