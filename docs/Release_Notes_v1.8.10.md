# DontForget v1.8.10 · Android / Windows / Linux

备份导入更直接，导出记录更易查找，build79／schema17。

## 更新

- 选取完整备份后自动预检，显示原文件名，减少重复选择与内部快照说明。
- 检查失败或取消后可重新检查；恢复仍需核对内容并明确确认。
- 修正附件恢复提示，准确说明附件与引用的核对范围。
- 保留最近20次导出记录，按需查看名称、时间和保存位置；兼容原有单条记录，不自动删除备份文件。
- 记录写入失败时保留已导出的文件和原记录；不保存备份密码或模型密钥。
- 无新依赖或数据库迁移，保留ARM64小包、语音交互与系统安全存储。

## 验收范围

- Android固定签名ARM64 APK／通用APK／AAB、Windows x64 Setup／Portable、Linux x64归档。Windows未做Authenticode签名，Linux基线Ubuntu24.04；Apple签名与设备验收继续推进。
- 源码、自动化、合成实机、普通应用升级和发行文件分别记录，见[阶段任务表](https://github.com/yarnway/dontforget/blob/main/docs/Next_Steps_2026-11-02.md)。真实语音／输入法、通知、桌面GUI、容量与故障恢复等未闭合项目仍保留各自范围。
- 导出记录描述保存位置，恢复时仍需重新选取并验证文件。加密保护导出文件；本机内容及自动恢复副本未加密，备份密码请自行保管。
