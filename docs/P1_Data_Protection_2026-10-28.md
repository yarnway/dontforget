## 已完成的功能

| 功能 | 入口与行为 | 保护边界 |
| --- | --- | --- |
| 系统安全存储 | 设置及“数据与安全”展示密钥状态、重试入口和明确确认的移除操作；默认模型及独立模型配置的密钥移至系统安全存储，SQL 仅保留随机引用和无密钥元数据 | 安全条目写入并精确读回后才提交 SQL；失败不降级成明文。旧明文迁移失败保留原数据并暂停使用旧密钥；缺失、锁定、损坏或配置绑定不匹配时不将引用当作 API key |
| 凭据生命周期 | 元数据绑定模型地址、模型、配置身份、启用状态及备用模型开关；设置偏好与草稿保存保留当前安全引用。移除只处理当前密钥，保留任务、附件和地址 | 新条目与 SQL 提交之间失败会回滚；旧条目清理授权保存在安全存储，待清理任务持久化，可重试。仅修改备份／SQL 的待清理引用无法授权删除任意条目；恢复后的旧界面／回调不能覆盖新代次 |
| 可选加密备份 | 设置 → 数据与安全，或计划与清单 → 备份。默认选中密码加密，密码至少 12 字符且重复输入；可主动取消加密。导入先解密、校验、预检，仍走现有恢复确认与回滚流程 | 密码不进入数据库、草稿或日志，无密码找回。错误密码、内容篡改、帧调换、截断或追加拒绝恢复，原库及原附件不变；所有新导出都排除模型密钥，包括加密导出 |
| 大附件处理 | 新 `.dfbackup` v2 文件以原始附件流打包，按 1 MiB 帧处理；显示阶段／进度并支持取消。单附件限制 512 MiB、合计 2 GiB，元数据另有限制 | 不把大附件整体读入内存或转为 base64；散列、长度和二次读取一致性检查，超限在内容读取前拒绝。导出完整后才交给系统文件保存；Linux 选择目录后用独立临时文件完成磁盘复制 |
| 恢复与旧包兼容 | 可读旧 v1 JSON 附件包；新包在独立 import 目录准备附件，逐文件 SHA-256 校验，保留现有任务、来源、图片、录音与附件引用关系 | 预览与准备之间源文件改变会拒绝；缺失媒体改为本机不存在的占位路径，不会误连目标设备上同路径的其他文件。密码／校验失败清理本次临时恢复目录，不覆盖原件 |
| 统一入口与临时文件 | “数据与安全”集中密钥、完整备份、导入预检及备份缓存管理。清理前显示数量／容量并确认；正常导出／取消后释放本次缓存 | 仅处理此库对应缓存目录内已知 export 文件，保护进行中的操作、原附件和 import 恢复材料；变化或旧代次的清理确认拒绝执行。原始内容的长期归档／保留策略仍待后续完善 |

系统凭据后端：macOS 使用系统登录 Keychain（适配现有 ad hoc 签名），iOS 使用非同步、仅本机且解锁时可访问的 Keychain，Android 使用插件的 KeyStore 保护加密存储并关闭错误后自动重置；Android 的云备份和设备转移规则排除凭据文件。Linux／Windows 使用插件系统后端，Linux CI 补齐 libsecret 开发依赖。macOS 登录钥匙串不等于 Data Protection Keychain；升级后的钥匙串访问提示与系统锁定行为须独立验收。

## 格式与回退

- v2 外层固定 magic、限长 JSON 头、分帧数据；可选 **AES-256-GCM**，随机 16 字节盐、8 字节 nonce 前缀加单调帧号，头、帧号和明文长度进入 AAD。每帧含独立认证标签，禁止帧重排。派生采用 **PBKDF2-HMAC-SHA256，600000 次**，拒绝降级参数及未支持参数。独立 Python AESGCM 夹具验证格式互通，密码与夹具均为公开合成测试数据。
- 导入先检查文件总长及帧大小，再派生密钥和解密；任务快照最多 32 MiB、manifest 最多 64 MiB、各表最多 100000 行。附件每份 512 MiB、合计 2 GiB 是实现上限；当前实际自动化大文件样本为 **40 MiB 原始附件**，不能当作满上限压力验收。
- 元数据和附件认证完成后进入原有 `BackupInspector`／数据库维护准入，恢复后通过全新 provider 容器读回。v1 JSON 原上限继续保留用于兼容；新 UI 默认导出 v2，旧客户端不能读取 v2。
- 本机任务数据库、媒体原件、自动恢复副本及旧备份没有因此全部加密。既有旧明文备份及 SQLite 历史页／系统备份可能仍含旧密钥，本轮不自动删除回退材料，也不承诺安全擦除；按需轮换旧密钥和人工管理历史备份。
- 新便携包均不携带模型密钥；跨设备恢复后须重新配置密钥。原始逻辑／SQLite 备份可能含本机安全引用，引用也不保证跨设备或被清理后的历史密钥可用；不能把文件恢复成功当作凭据迁移成功。旧程序回退需使用对应版本的备份。
