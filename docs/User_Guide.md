# DontForget (别忘了) - 完整用户使用指南

欢迎使用 **别忘了 (DontForget)**！这是一款主打**“端侧绝对隐私安全 + 大模型智能解析 + 3D 全息科幻美学”**的全平台个人备忘录与智能任务调度助手。

---

## 1. 软件安装与初次启动

### 1.1 获取软件
您可以从项目的 Release 发行版中下载对应平台的安装文件：
- **独立安装引导版 (`DontForget_Setup_v1.x.x.exe`)**：
  - 双击运行安装向导，一键安装至系统，自动创建桌面图标与开始菜单快捷方式，支持完整的 Windows 卸载程序。
- **绿色便携免安装版 (`DontForget_Portable_v1.x.x.zip`)**：
  - 下载解压到任意文件夹，双击 `dont_forget.exe` 即可直接启动，配置和数据完全存储在本地，适合放入 U 盘随身携带。

### 1.2 系统兼容性保障
- 支持 **Windows 11、Windows 10、Windows 8/8.1 以及 Windows 7 SP1**（64位）。
- 软件已在发行包中完整内嵌了 Visual C++ 2015-2022 CRT 运行时与 DirectX 图形组件，**无需提前在电脑上安装任何运行库**，在纯净新系统中即可秒开。

---

## 2. 初始配置：大模型服务接入

首次启动应用时，建议前往「设置」配置您的大模型服务凭据（BYOK: Bring Your Own Key）：

1. 点击主界面右上角的 **齿轮设置图标** ⚙️；
2. 软件内置了主流大模型服务商的**一键快捷预设**：
   - **DeepSeek 预设**：一键填充 API 基础地址（`https://api.deepseek.com/v1`）与推荐模型标识（`deepseek-chat` 或 `deepseek-v4-flash-vision-exp`）；
   - **Gemini 预设**：一键配置 Google Gemini 兼容网关地址与推荐模型标识；
   - **自定义服务商**：支持任何遵循 OpenAI 格式标准的第三方大模型 API 或个人在本地部署的模型（如 Ollama、vLLM、OneAPI 等）；
3. 输入您的 **API Key**，点击「保存配置」；
4. **语言切换**：在设置页面可随意在中/英/日三语之间切换，界面所有元素与数据图表将实时平滑变更。

> [!NOTE]
> **绝对隐私承诺**：您的 API Key 与所有记录内容仅保存在您电脑本机的 SQLite 数据库中，请求直接由您的客户端发往模型服务商官方接口，无任何第三方服务器中转。

## 3. 多模态记录与智能创建

底部输入栏支持全方位的多模态信息输入：

### 3.1 纯文本智能输入
- 在输入框中输入任何自然语言，例如：
  - *“明天下午 3 点和李总开视频会议讨论 Q3 预算”*
  - *“周五上午 9 点的高铁去北京出差”*
  - *“下周一前提交年度工作总结”*
  - *“每天早晨 8 点记得按时吃降压药”*
- 按键盘 **Enter** 或点击发送按钮，大模型将自动提炼核心事项、智能推算提醒时间并分类。

### 3.2 语音即时输入
- 支持点击或长按麦克风图标进行录音。录音时界面会呈现呼吸动效，松手或点击停止后，录音文件将自动保存至本地并由 AI 进行智能提取。
- 待办卡片生成后，卡片上会常驻语音播放按钮，点击即可随时复听原始语音。

### 3.3 图片与截图识别
- 点击底部 **“+”** 号可选择「从本地相册选取」或「快速截图上传」。
- 若您拍摄或截取了通知单、合同签署页、白板便签或聊天记录截图，具备 Vision 能力的大模型将自动读取图中文字，精准提炼待办任务。

### 3.4 视频与文档附件关联
- 支持将本地视频片段或工作文档关联至待办中，卡片上将呈现专属文档/视频微标，点击即可快速预览或调用系统默认程序打开。

## 4. 智能提醒与「提前量」机制

传统提醒软件往往只能在事件开始的精确时间点发出提醒，容易让人措手不及。在 **v1.2.4+** 中，DontForget 引入了大模型专属的**智能提前量（Lead Time）评估引擎**：

| 事项类型 | 场景举例 | 智能提前量策略 | 提醒理由说明 |
|---|---|---|---|
| **会议 / 线上沟通** | 下午 3 点开会 | 提前 **15 ~ 30 分钟** 提醒 | 留出准备资料、连入会议室的时间 |
| **交通 / 差旅出行** | 明早 9 点赶高铁 | 提前 **60 ~ 120 分钟** 提醒 | 留出出门路途通勤与车站安检时间 |
| **工作截止 / 汇报** | 周五前提交报告 | 提前 **1 ~ 3 小时** 提醒 | 留出收尾整理与复核检查的时间 |
| **即刻 / 准点事项** | 10 分钟后吃药 | 提前 **0 分钟**（准点提醒） | 准时触发即刻行动 |
| **非定时普通事项** | 买牛奶、复习英语 | 根据重要程度安排在今晚 20:00 或明早工作时间 | 避开深夜打扰，合理利用精力 |

*所有提炼出的提醒理由均会贴心地在事项摘要中注明（例如：“开会时间 15:00 (提前15分钟提醒准备入会)”）。*

## 5. 3D 全息 AI 粒子系统交互

主界面的背景由精密的 3D 空间动力学引擎实时绘制，具备高度的视觉美感与生命力：

1. **粒子 LOGO 构成**：由 555 颗空间折纸光粒子组合成立体 LOGO 造型，并带有双倾角的宇宙空间天体环。
2. **深空星光与十字星芒**：背景分布 150 颗自主明暗呼吸的深空恒星，其中 32 颗高能恒星会在光度达峰时绽放 4 芒光学衍射十字星刺。
3. **线束脉冲传输**：粒子之间的光纤细丝上，有白蓝色高能光子以不同速率飞驰传输，犹如大模型神经网络正在高速推理。
4. **鼠标阻尼波纹推散**：
   - 移动鼠标：激起扩散能量涟漪，粒子被向外柔和推开，并带有流体尾流拖曳感；
   - 点击屏幕：引爆 3D 冲击激波，粒子向周围散开；
   - **慢速优雅复位**：推散后的粒子将在微重力阻尼模型下，如同星云般缓慢、丝滑地在数秒内缓缓凝聚复原，观感极致放松。

## 6. 极简任务看板与卡片操作

- **纯图标分类**：
  - 🔥 **红色火苗**：高优先级核心事项
  - ⭐ **橙色星星**：重要长线规划
  - ⚡ **蓝色闪电**：日常紧急协同
  - ☕ **绿色咖啡**：琐碎休闲事项
- **卡片交互**：
  - **右键或长按**：呼出上下文菜单，支持编辑修改、标记完成/未完成、彻底删除；
  - **拖拽归类**：长按卡片并拖动至其他分类区域释放，可随时调整事项分类；
  - **到期强提醒**：事项到期时会弹出全局提示框，支持一键推迟（Snooze 5分钟）或直接标为已办。

## 7. 数据看板与清理维护

- **数据统计**：点击顶部栏的图表图标 📊，即可查看整体任务完成率（动态环形图）与分类比例（纯图标饼图）。
- **一键清理历史完成**：点击顶部扫把图标 🧹，可一键清空全部历史已完成任务。
- **清除提示信息**：点击禁音通知图标，可一键清除全部历史弹窗提示与错误信息。
- **状态指示灯**：顶部栏标题旁的呼吸指示灯可感知大模型状态（绿色常驻代表待机就绪，青蓝色高亮呼吸代表正在解析提炼中）。
