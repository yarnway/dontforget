# DontForget (别忘了) - 完整用户使用指南

欢迎使用 **别忘了 (DontForget)**！这是一款以本地任务管理、录音回放和可选大模型解析为核心的个人备忘录。当前公开候选为 [v1.7.0-rc.29](https://github.com/yarnway/dontforget/releases/tag/v1.7.0-rc.29)，尚未发布稳定版；平台支持与实测范围见 [v1.7 验收总表](Release_Acceptance_v1.7.md)。

---

## 1. 软件安装与初次启动

### 1.1 获取候选包

从 GitHub 候选 Release 获取与平台对应的附件，版本与签名状态以发布说明为准。

- Windows：Setup EXE 为安装包，Windows Portable ZIP 为解压启动包。“便携”指启动方式，不能据此假定数据库跟随程序目录或 U 盘迁移。
- Android：使用 test-signed APK 进行设备验收；AAB 用于后续分发流程，不是直接安装文件。
- macOS：unnotarized ZIP 尚未公证。
- iOS：unsigned IPA 尚未签名，不能直接安装到 iPhone。
- Linux：提供 x64 tar.gz，真实桌面功能仍需验收。

### 1.2 验收范围

Windows/macOS/Linux 已执行 CI 原生启动检查；Windows 另有安装、同候选覆盖和卸载检查。系统版本兼容、真实旧库升级和其他设备功能应以[验收台账](Release_Acceptance_v1.7.md)为准。升级前保留数据库与附件副本，不要为绕过签名冲突卸载有数据的版本。

## 2. 初始配置：大模型服务接入

> 当前工作区的记录与提醒优化尚未计入公开候选：可先直接使用本地记录，在输入区选择提醒时间或“仅备忘”；今天视图、原文保存、跨重启草稿、AI 时间建议和更多延后选项的范围见[分阶段清单](Recording_Reminders_Phases.md)。使用 AI 时再按下方步骤配置。

工作区新增的优先流程：输入后从时钟菜单检查时间，再发送；原文先保存，AI 结果从任务卡“确认 AI 解析结果”预览、编辑和确认。今天视图把紧急事项、记录与待确认、学习分别展示。从“更多功能 → 今日学习队列”设置每日总词量和新词上限，按单词反馈“认识／模糊／不认识”；超额内容保留，之后继续。出现“事项已保存但系统提醒未更新”时，可直接点击“修复提醒”检查权限和重试。旧公开候选仍以其对应版本说明为准。

首次启动应用时，建议前往「设置」配置您的大模型服务凭据（BYOK: Bring Your Own Key）：

1. 点击主界面右上角的 **齿轮设置图标** ⚙️；
2. 软件内置了主流大模型服务商的**一键快捷预设**：
   - **DeepSeek 预设**：一键填充 API 基础地址（`https://api.deepseek.com/v1`）与推荐模型标识（`deepseek-chat` 或 `deepseek-v4-flash-vision-exp`）；
   - **Gemini 预设**：一键配置 Google Gemini 兼容网关地址与推荐模型标识；
   - **自定义服务商**：支持任何遵循 OpenAI 格式标准的第三方大模型 API 或个人在本地部署的模型（如 Ollama、vLLM、OneAPI 等）；
3. 输入您的 **API Key**，点击「保存配置」；
4. **语言切换**：在设置页面可随意在中/英/日三语之间切换，界面所有元素与数据图表将实时平滑变更。

> [!NOTE]
> **数据范围**：任务、媒体索引和 API Key 保存在本机，目前没有应用层加密。使用 AI 解析时，相关内容会发送到您配置的模型接口；自定义地址的服务归属需自行核对。局域网同步使用 HTTP，请仅在可信网络使用。

## 3. 多模态记录与智能创建

底部输入栏支持全方位的多模态信息输入：

### 3.1 纯文本智能输入
- 在输入框中输入任何自然语言，例如：
  - *“明天下午 3 点和李总开视频会议讨论 Q3 预算”*
  - *“周五上午 9 点的高铁去北京出差”*
  - *“下周一前提交年度工作总结”*
  - *“每天早晨 8 点记得按时吃降压药”*
- 默认按键盘 **Enter** 或点击发送按钮提交；设置中可改为“仅发送按钮”，此时 Enter 换行，Shift+Enter 在两种方式下均换行。正在输入法组词时不会提交。文字先保存到本机，再按配置后台请求 AI；无明确时间时保留为备忘，可从时间菜单选择提醒或仅备忘。
- 输入文字和时间选择自动保存到本机。保存失败保留输入；保存期间继续编辑时，原提交副本会单独保留。出现“待核对的记录”可查看、复制、丢弃或追加恢复，重新发送前请核对是否已经保存。重启不会自动调用模型或重新提交记录；恢复备份会以所选数据中的草稿为准。
- 任务卡出现“确认 AI 解析结果”后，可预览并编辑标题、说明、事项截止时间和提醒时间，选择事项后确认保存。取消保留原记录和提案；确认前不安排建议提醒。图片、文件、视频和语音解析的 AI 时间也需确认。用户明确输入或手动选择的本地提醒可直接保存。
- 事项截止时间和提醒时间独立编辑，延后只改变提醒。旧数据不补造截止日期；AI、手动和未知的提醒来源分别显示。

输入框支持全选、复制、剪切和粘贴。先点一下进入文字编辑，再长按可选择文字或粘贴；桌面右键可打开编辑菜单。粘贴多行内容不会自动发送。空白且未进入编辑时长按仍为录音；已进入编辑时可点击麦克风开始录音。

### 3.2 语音即时输入
- 支持点击或长按麦克风图标进行录音。录音时界面会呈现呼吸动效，松手或点击停止后，录音文件保存至本地；未配置 AI 密钥时会保留关联原声任务，配置模型后才尝试智能提取。
- 待办卡片生成后，卡片上会常驻语音播放按钮，点击即可随时复听原始语音。

### 3.3 图片与截图识别
- 点击底部 **“+”** 号可选择「从本地相册选取」或「快速截图上传」。
- 若您拍摄或截取了通知单、合同签署页、白板便签或聊天记录截图，具备 Vision 能力的大模型将自动读取图中文字，精准提炼待办任务。

### 3.4 视频与文档附件关联
- 支持将本地视频片段或工作文档关联至待办中，卡片上将呈现专属文档/视频微标，点击即可快速预览或调用系统默认程序打开。

## 4. 智能提醒与「提前量」机制

传统提醒软件往往只能在事件开始的精确时间点发出提醒，容易让人措手不及。在 **v1.2.4+** 中，DontForget 引入了大模型专属的**智能提前量（Lead Time）评估引擎**：

| 事项类型 | 场景举例 | 智能提前量策略 | 提醒理由说明 |
|---|---|---|---|
| **会议 / 线上沟通** | 下午 3 点开会 | 提前 **15 ~ 30 分钟** 提醒 | 留出准备资料、连入会议室的时间 |
| **交通 / 差旅出行** | 明早 9 点赶高铁 | 提前 **60 ~ 120 分钟** 提醒 | 留出出门路途通勤与车站安检时间 |
| **工作截止 / 汇报** | 周五前提交报告 | 提前 **1 ~ 3 小时** 提醒 | 留出收尾整理与复核检查的时间 |
| **即刻 / 准点事项** | 10 分钟后吃药 | 提前 **0 分钟**（准点提醒） | 准时触发即刻行动 |
| **非定时普通事项** | 买牛奶、复习英语 | 根据重要程度安排在今晚 20:00 或明早工作时间 | 避开深夜打扰，合理利用精力 |

*所有提炼出的提醒理由均会贴心地在事项摘要中注明（例如：“开会时间 15:00 (提前15分钟提醒准备入会)”）。*

## 5. 工作区与常用入口

v1.5.1 修订界面使用静态背景和统一留白，减少持续动画对阅读的干扰。顶部保留搜索、情境、更多功能和设置；图谱、专注、复习、导出、统计和清理可从“更多功能”进入。

设置页底部固定显示“保存配置”和“备份已保存的数据”，无需滚动到长表单末尾。备份会保存已提交的设置、任务和媒体索引，不包含附件文件本体；含 API Key 的本地备份请妥善保管。备份失败会显示提示，排除存储问题后可重试。

## 6. 极简任务看板与卡片操作

- **响应式看板**：宽窗口使用四象限，窄窗口改为单列滚动；分类名称与颜色同时显示。
- **已完成任务**：默认折叠，点击“已完成”及数量展开；展开后仍可查看详情、播放原录音。
- **卡片交互**：
  - **右键或长按**：呼出上下文菜单，支持编辑修改、标记完成/未完成、彻底删除；
  - **拖拽归类**：长按卡片并拖动至其他分类区域释放，可随时调整事项分类；
  - **到期强提醒**：事项到期时会弹出全局提示框，支持一键推迟（Snooze 5分钟）或直接标为已办。

## 7. 数据看板与清理维护

- **数据统计**：从顶部“更多功能”进入数据看板。
- **清理已完成任务**：从“更多功能”进入清理操作，确认前先核对待删除数量。
- **清除提示信息**：从“更多功能”清除当前提示。
- **状态指示灯**：显示应用就绪或正在处理；“就绪”不代表外部 AI 服务已验证连通。

## v1.7 复习与专注

- 从任务菜单将任务转为复习卡片，再从“更多功能 → 复习卡片”进入。卡片先显示题目，点击“查看答案”可阅读说明和子任务；“记住了”推进阶段，“再复习”回到第一阶段。保存完成后才显示下次复习日期；保存失败可重试。
- “没有复习卡片”和“今天没有待复习卡片”分别表示未启用卡片与已安排在之后的日期。普通任务转成的复习卡片默认供应用内查看；通过下方词汇学习计划创建的卡片会同时保存学习与后续复习提醒。
- “更多功能 → 专注模式”可查看和切换当前状态。只在当前应用会话生效，退出重开后关闭；暂停 Q3/Q4 提醒，Q1/Q2 保持原行为。已经送达的通知不移除，关闭专注不会重放已过期提醒。
- 策略更新过程中显示进度；部分系统请求失败会显示重试入口，所选开关状态不等于全部系统请求已完成。办公或深度专注情境也会独立抑制 Q3/Q4，面板会提示这一影响。
- macOS 的原生“更多功能”菜单支持 `Cmd+K`；工具已打开或正在编辑详情时不再叠加新的工具窗口。窄屏或放大字体下可滚动阅读内容和操作按钮。

## v1.7 词汇学习引导

例如准备四级、希望每晚 20:30 学习 10 个词，可以按以下步骤创建：

1. 在设置中保存可用的模型服务。打开“更多功能 → 词汇学习计划”；桌面也可按 `Cmd/Ctrl+K` 搜索该工具。
2. 选择大学英语四级、六级、考研英语、雅思或托福，每天 5/10/15/20 个词，本次准备 1/3/7 天。基础与偏好可填写“基础较弱，先学校园词汇，每晚 20:30 学习”。
3. 点击“让 AI 准备计划”。模型返回词汇、IPA 音标、词性、释义、常用搭配、原创双语例句和建议时刻，计划按天分批准备并显示进度，全部完成后才开放保存，此时不会创建事项或系统通知；失败后可调整词量和天数重试，也可取消生成。
4. 预览按单词展示学习卡片，用“上一个词 / 下一个词”阅读；点“编辑词汇”修改文本，再点“查看卡片”读回。可在事项详情中继续编辑。校对每批标题、词汇与例句，调整首次学习日期和每日时刻。确认后每日一批加入“重点跟进”；重复确认不会重复创建。提醒实际送达取决于系统权限和调度，可在设置查看状态。
5. 进入“复习卡片”，逐词尝试回忆，再显示释义与例句；翻到下一词后重新隐藏答案。看完本组后再反馈。学习批次“已记住”后，下一次间隔依次按 1、2、4、7、15 天安排；“需复习”回到 1 天。按本地日历保留学习时刻，每次反馈更新同一事项的提醒。

关闭或切换工具会保留草稿；学习偏好、计划预览和编辑会保存到本机，重启可继续，放弃预览需确认。恢复备份会使用所选数据中的草稿。完成、删除事项或关闭该卡片的复习会停止对应提醒；手动清除提醒时间后仍可在应用内复习。复习卡片仍支持按批次反馈；集成工作区新增“今日学习队列”，可按单词反馈“认识／模糊／不认识”，独立保存掌握度并按每日额度安排。

默认复习间隔不代表个人最优记忆曲线。模型生成内容可编辑，不保证官方词库覆盖或考试成绩；音标、词义、搭配和例句应结合可信学习材料校对。旧计划的已有释义和例句仍可按卡片阅读，缺失字段不自动编造；自定义编辑不再符合卡片格式时，完整笔记仍以文本展示。

## v1.7 手机输入与学习提醒（+30）

- iOS / Android 左侧切换文字与语音，默认轻点输入文字；空白且未聚焦时可直接按住录音，文字编辑中长按仍保留选择、复制、剪切、粘贴。已有草稿时可切换到“按住说话”，草稿不会丢失。
- 按住录音时显示底部圆弧面板，中间提示当前松手动作。**上滑往左取消，上滑往右转文字并编辑**；允许先上滑再左右选择，滑回输入区恢复普通松手发语音。取消不发送。转写追加到可编辑草稿，必须点击“发送”才交给任务解析；即使设置为回车发送或重开应用，也先保留文字供检查。
- 附件入口移至输入框右侧。“回车键发送”隐藏手机最右侧发送按钮；“发送按钮”模式显示该按钮，回车换行。中日文尚未确认的组词不会误发送。桌面保留既有输入布局。
- 到期学习提醒可点“开始复习”，直接打开对应批次；仅打开卡片不会确认、完成或重排提醒。反馈前显示下一次复习日期，保存后继续显示确认结果。按批次反馈的现有策略不变。

## v1.7 操作结果提示

保存、失败和撤销提示改为右上方限宽卡片，适配明亮与暗黑主题，不推动工作台，也不抢走输入焦点。保存成功显示“修改已保存”；数据已保存但系统提醒尚未更新时显示单独的警示。长说明在正文区域滚动，关闭和撤销按钮保持可见；提示之外的输入与按钮可继续操作。

普通提示至少显示 8 秒，可点击关闭；带“撤销”的提示和辅助导航模式下的提示保留到处理或替换。桌面按 F6 可在提示操作与原输入位置之间切换，Enter 执行选中的操作。一次显示一条，避免连续堆叠遮挡。

## v1.7 情境摘要与 CSV

- “情境摘要”展示本次应用会话中静音的待处理任务；专注开关及办公/深度专注情境的到期拦截均可进入摘要。已完成、删除或重新安排的提醒轮次会移出列表，关闭页面不会完成任务；退出应用后不保存这份会话摘要。
- 摘要可以完成当前轮次或打开详情。循环任务完成后安排下一次，不会因旧摘要按钮被重复点击而再次推进日期；通知同步失败会单独提示。
- “导出 CSV”会导出全部已保存任务，包括已完成任务；选择位置后保存，可取消、重试并复制文件位置。导出开始时固定任务快照，保存结果显示实际导出数量。
- 表头、状态和内置枚举跟随中文/English/日本語，日期使用设备本地时区，空日期留空。用户填写的文字保留原语言；紧急程度为文字，不是提前提醒分钟数。
- 格式采用 UTF-8 BOM、CRLF 行分隔及 CSV 引号转义。可能被表格解释为公式的文本添加前导单引号。文件不含 API Key、应用设置及附件文件，也不能用于备份恢复。
- P0 集成版在原 16 列末尾追加“本地事项截止时间”，与原有提醒时间分开；依赖固定列数的导入工具需适配。


## v1.5.2 工作台操作更新

- 手机窄屏在顶部选择四个分类之一，当前列表使用剩余高度；短窗口可以横向滚动分类。桌面继续同时显示四象限。
- 分类按钮可用方向键、Home、End 切换；任务卡右侧的“任务操作”菜单支持键盘和触屏，完成按钮扩大到 48px。
- 搜索覆盖标题、摘要和子任务。Ctrl/Cmd+F 打开，Esc 退出；输入短暂停顿后更新结果。
- 已完成和长期停留的备忘继续折叠，展开后可滚动浏览；长标题与状态标签适配放大字体。
- 同名附件导入会保存为不同副本，已有附件不会被后导入的同名文件覆盖；备份仍只包含附件路径。


## v1.7 搜索与任务浏览

- 点击顶部搜索，或按 `Ctrl/Cmd+F`，即可浏览全部任务。也可选择待办、今日提醒、提醒时间已过、已完成；时间筛选只包含未完成任务，“今日”使用设备当前时区的自然日。提醒时间可能早于事件开始或截止时间。
- 在搜索框输入空格分隔的关键词，例如 `发布 清单`，会查找同时包含这些词的任务，词语可以分别出现在标题、摘要或子任务中；英文不区分大小写。
- 选择“提醒时间优先”会把较早提醒的任务排在前面，无提醒时间的任务排在末尾；“最近创建优先”按创建时间倒序。同一时间的任务保留默认相对顺序。
- 搜索框的清除按钮只清空文字，保留筛选条件；“重置条件”同时清空文字、恢复全部任务和默认排序。`Esc` 或返回按钮退出搜索；重新打开时从全部任务开始。
- 今日提醒与提醒时间已过的筛选在前台每分钟及应用恢复前台时更新；完成、编辑和删除后的结果随保存结果更新。CSV 的相关列标题与状态也按提醒时间命名。


## v1.7 数据看板与复盘

- 从“更多功能”进入数据看板，查看所有已保存任务的总量、完成率和分类分布；包含所有日期的已完成与待办任务。分类条旁的数字是任务数。
- 未配置模型时可直接生成本地统计报告。配置了模型时会尝试生成 AI 报告；模型未返回可用结果时，会明确提示并展示本地统计，可点击重试。统计复盘目前使用首个启用配置，不代表已验证跨供应商降级。
- 报告顶部标明来源。重试期间保留旧报告；任务或设置变化后会提示重新生成，避免误把旧结果当成实时数据。
- 点击复制会带上报告来源；只有系统剪贴板写入成功才提示完成，失败可以重试。离开页面后报告不持久化，下次进入可重新生成。
- 窄屏或大字体使用纵向布局，向下滚动可查看分类和报告；宽屏并排显示，深浅主题均支持。

## v1.7 详情编辑与工具查找

- 打开事项详情后可修改标题和补充说明，底部“保存修改”始终可见；分类、提醒时间等控件在窄窗口下换行。
- “下一个 20:00”选择最近一次尚未过去的本地 20:00；时间已过时会选下一天，并在详情展示具体日期。详情的“刷新状态”按需查询已保存轮次的系统安排和通知权限；“已提交”不表示已经送达，状态无法读取时显示未知。
- 需要替换整段文字时，在标题或说明的文本菜单中选择“全选”，再输入新内容。桌面可右键打开文本菜单；仅修改而未保存的文字不会自动提交。
- 从“更多功能”或 `Ctrl/Cmd+K` 打开工具面板，可按名称、说明或指令搜索。用上下方向键选择、Enter 打开、Esc 关闭，选中项会自动滚动到可见区域。中文输入法组合过程中，确认候选词不会执行工具。
- 报告以所有已保存任务为范围，不是周报；完成比例反映记录状态，不能用来推断实际耗时或工作质量。模型建议仍需结合实际任务判断。

- 返回工作台前，未保存的修改会提示“继续编辑 / 放弃修改 / 保存并返回”。保存失败会保留草稿；系统提醒同步失败但任务已经保存时，会单独提示提醒状态。
- 知识图谱每页最多展示 120 项及页内关联，可搜索标题与说明、按分类筛选或翻页。“任务列表”按需显示全部匹配事项，适合大量数据和键盘/无障碍浏览。
- 图谱点击节点查看摘要，双击或“查看详情”打开编辑；拖动节点调整位置，拖动空白处平移，用右上角按钮重新居中。布局保持静止，选择节点不会重新打散位置。

### 工作区工具面板

导出 CSV 与专注模式在工作区内打开。宽屏右侧显示工具，窄屏临时显示工具内容；底部输入栏始终保留，可继续编辑草稿。关闭工具或切换工具不会清空输入。导出进行中等待保存选择器返回后才能关闭或切换工具；原生保存选择器自身仍是系统模态窗口。

### 工作区工具与编辑快捷键（1.7.0+14）

复习、情境摘要、图谱、数据看板、目标协作、专注和导出共用非遮挡面板。宽屏位于右侧，窄屏切换工作区，底部输入保持可用；键盘弹出或窗口变矮时看板改为单分类布局。面板关闭不清空主输入草稿。

- `Cmd/Ctrl+K` 打开工具选择，`Esc` 关闭当前面板；中文或日文输入法正在组合文字时，快捷键让给输入法。`Cmd/Ctrl+F` 返回工作区搜索；非输入状态下可用 G/C/F/R/E/B 打开图谱、摘要、专注、复习、导出和看板。
- 任务详情中 `Cmd/Ctrl+S` 保存并返回，macOS 也可使用应用菜单中的“保存修改”；`Esc` 请求返回。有未保存修改时可继续编辑、放弃或保存后返回；输入法组合期间不触发保存或离开。
- 目标协作尚未提交的文字在切换、关闭工具后保留并保存到本机，重启可继续；放弃需确认。恢复备份后使用所选数据中的草稿，执行失败保留文字供重试。
- 复习保存、导出保存选择及报告生成期间阻止工具切换和关闭，避免重复操作。系统原生保存选择器仍采用系统模态交互。

编号候选使用 `v版本-rc.构建号`（例如 `v1.7.0-rc.14`），与 `pubspec.yaml` 的版本、构建号和源码提交共同核验。候选 Release 标记为预发布；所有稳定版门槛完成前，不标记为最新稳定版。


### 灵动岛与锁屏实时活动（候选功能）

在 iOS 16.2 及以上设备打开一条未来 8 小时内到期的未完成、未确认提醒，保存修改后点击“在灵动岛显示”。支持的设备会显示灵动岛，其他设备使用锁屏实时活动卡片。一次显示一条，可在详情点击“结束实时活动”。普通系统通知仍照常安排。

修改提醒后更新卡片；删除、完成、确认或恢复数据后清理活动。到期时前台应用会结束活动；应用在后台时系统可先显示“已到期”，回到应用后清理。点击卡片仅打开当前有效事项，不自动完成或确认；过期的数据版本、已删除或已改期的旧链接不会误开任务。系统关闭实时活动时，界面会显示状态并提供重试。

公开 iOS 候选未签名；实时活动扩展也需要匹配的开发或分发描述文件。当前候选的实际灵动岛展示、点击和结束仍按发布验收总表记录，不将构建成功视为真机验收。


### 通知快捷操作与通知自检（2026-10-28）

系统提醒提供“完成本次提醒”“15 分钟后”“1 小时后”；周期任务另提供“跳过本次”。Android 标准通知最多显示 3 个动作，因此周期通知显示“完成／15 分钟后／跳过本次”，1 小时延后仍可在应用内选择；非周期通知显示完成及两种延后。iOS/macOS 周期通知保留四项。点击通知正文仍打开应用详情，不额外增加“打开”按钮。完成与跳过沿用当前任务的周期推进规则；跳过不会标记任务完成。延后只改变提醒时间，保留事件／截止时间和周期锚点。

运行中的应用由主 isolate 处理动作；Android/iOS 的系统后台回调先将动作写入本机待处理文件，再唤醒正在运行的处理器。应用已终止时，动作等待下次正常启动、存储检查和任务加载完成后执行，不会由后台 isolate 打开数据库。处理时再次核对当前数据集、提醒时刻和通知修订号；任务已修改、已完成、已删除或数据已恢复时，旧通知动作会被丢弃。同一轮同一动作重复回调不会重复生效。文件最多保留 32 条，超限保留最近条目。

延后从点击时刻计算。如果应用很久后才消费，目标时间已经过去，则改为处理时刻后至少 1 分钟，避免刚启动又立即弹出。任务保存成功而系统取消／排程失败时，会保留现有通知待修复状态；可到通知修复页重试。更改界面语言后，应用会重新注册动作标题并通过现有排程流程更新未来通知；系统已保留的旧横幅仍可能保留旧文字，可关闭旧横幅。

在设置的通知区域打开“通知自检”，查看当前权限、系统待安排通知数、待修复数量和 journal 当前保留的最近失败时间。这里是按需读取的系统／本机记录，读不到时显示“暂不可用”；没有失败记录也不能证明历史上从未失败。

点击“发送测试通知”，应用先取消上一条测试请求，再提交 5 秒后的独立测试通知。它明确标记为测试，不创建任务、不进入业务提醒路由、不写业务 journal。界面只报告“已提交系统”：实际送达取决于系统权限、专注模式及平台调度。权限被拒绝或排程失败会单独提示。Windows/Linux 缺少本应用可用的原生定时通知时，按钮不可用并提示“应用需保持运行”；这不表示通知问题已经修复。

### 任务卡与详情中的项目、标签和清单

普通任务卡展示项目、最多 3 个标签（其余显示 `+N`）及“已完成／总数”的清单进度。展开清单后可勾选，修改保存到已有 details_json。点击详情可编辑项目、增删标签、增删／排序／勾选清单，再使用“保存修改”；离开时仍有未保存修改提示。规划面板继续负责批量管理。

旧数据中的 sub_tasks 继续标注为“微习惯”，作为只读内容展示；不会自动转换为清单。两者同时存在时，可操作清单为主，微习惯保留为次级内容。药物、出行和学习等特殊任务沿用专用面板或仅展示清单进度，详情不提供会改变专用面板语义的通用清单编辑器。

详情沿用现有详情与普通字段保存命令。若项目／标签／清单已保存，而后续标题等字段保存失败，界面会保留未提交草稿并提示失败；可直接重试，已保存的清单不会重复追加。数据恢复期间暂停编辑，旧页面不能把修改写入新代次。

本轮源码与自动化测试不代表原生设备验收。仍需在 macOS/iOS/Android 人工检查通知展开后的按钮、前后台和终止后动作、系统权限／专注模式、语言切换与系统实际投递。
