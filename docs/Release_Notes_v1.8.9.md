# DontForget v1.8.9 · Android / Windows / Linux

备份导出优化与七天学习预测，build78／schema17。

## 更新

- 完整备份支持自定义名称，留空自动命名；名称和输入法候选确认在导出前检查。
- 最近导出精简为名称、时间、加密状态与附件数，保存位置按需查看；兼容旧导出记录。
- 修复文件已导出但记录保存失败时的误报，保留已保存文件；统一备份卡片宽度、圆角裁剪和间距。
- “未来7天”增加预计安排，可按认识／模糊／不认识估算后续复习与待排，保留已排期视图，默认收起。
- 预测沿用每日额度、新词额度和自定义间隔，只读模拟；不修改词条、进度、排期或通知。
- 无新依赖或数据库迁移，保留ARM64小包、原有语音交互与本地凭据。

## 验收范围

- Android固定签名ARM64 APK／通用APK／AAB、Windows x64 Setup／Portable、Linux x64归档。Windows未做Authenticode签名，Linux基线Ubuntu24.04；Apple签名与设备验收继续推进。
- 源码、自动化、私有合成实机、普通应用升级和发行包分别记录，见[阶段台账](https://github.com/yarnway/dontforget/blob/main/docs/Next_Steps_2026-11-02.md)。合成备份目录验收不替代原生文件选择器及带附件GUI恢复，情境预测不代表个性化学习效果。
- 模型密钥排除在导出之外。加密保护导出文件，本机内容及自动恢复副本未加密；请保管备份密码。
