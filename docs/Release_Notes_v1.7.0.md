# DontForget v1.7.0 · Android / Windows / Linux

本次发布包含 Android、Windows x64 和 Linux x64，构建号59、数据库schema17。macOS／iOS仍在独立验收，未包含在本次Release。

## 主要更新

- 本地优先记录：文字、录音、图片和文件附件；主输入草稿持久化，编辑后明确发送，支持中文／English／日本語及明亮／暗黑外观。
- 录音保留“按住录音，上滑往左取消、往右转文字供编辑，普通松开保存原声”的交互；麦克风后台中断、取消及旧回调隔离加强。
- Android新增系统文字／链接分享入口，先进入独立分享草稿，编辑确认后保存为本地备忘；保留主输入原文，接收和重启不自动调用AI或安排提醒。
- 设置首页精简为常用偏好，AI服务、通知、数据保护、内容管理和设备同步按需进入；偏好保存不再重写密钥。
- 支持搜索、筛选、批量管理、回收站、关联、周期提醒和词汇学习计划；AI提案先预览确认，未配置模型也可本地保存。
- 备份包含数据库及附件原件，支持普通备份和密码加密备份；新增大容量回归、取消清理和恢复保护。已测2GiB普通备份、单份512MiB加密附件；不代表2GiB加密或所有故障场景已验。
- Windows增加旧目录迁移保护、设备独立窗口偏好、安装／同包升级／卸载及启动检查；Linux完成原生打包与隔离启动检查。
- Android采用固定发行签名证书并核对APK与AAB签名，后续正式更新沿用此证书；发布附带三平台清单、SHA-256、构建来源及验收报告。

## 下载与运行

- **Android**：安装 `DontForget_Android_v1.7.0.apk`，最低Android7／API24。AAB供后续商店分发准备，不能直接安装；本次不宣称已通过Google Play审核。证书SHA-256：`3db49656984fb848a73b1e8d056846b97e2a7caf47c9a9ae74f475cdbb79e9f1`。
- **Windows x64**：选择Setup安装器或Portable ZIP；Windows包未做Authenticode签名。便携包仅指解压启动方式，数据位置请看使用指南。
- **Linux x64**：解压tar.gz，在完整桌面会话中执行 `./dont_forget`。CI使用Ubuntu24.04；需要GTK3、libsecret、AppIndicator及GStreamer base／good运行时，其他发行版桌面兼容性继续验收。
- 下载后可使用附带 `SHA256SUMS.txt` 核对完整性。Windows安装／升级／卸载及Windows／Linux启动报告属于隔离合成验收，完整真实通知和桌面交互矩阵仍单独推进。

## 升级与已知限制

- 这是首个采用上述固定发行证书的Android版本；此前临时测试签名可能无法直接覆盖升级。遇到签名冲突时请保留原App，先导出并保留备份和附件，核实恢复后再迁移，勿直接卸载含数据版本。独立QA47与发行身份不同，不会自动迁移QA数据。
- 腾讯云录音文件识别为需自行配置的预览功能，默认关闭；需要开通服务并填入AppID、SecretId、SecretKey，会上传录音并可能计费。当前未完成真实账号的中文／英文／混合语音识别验收，不将本次发布写作该服务已全部验证；未配置时可保存和播放原声。既有凭据不随Release分发。
- 部分输入法切换后曾出现键盘按键区空白，重开输入连接或重新切换输入法后恢复，根因仍待定位。
- Android系统分享目前仅支持文字／链接，不支持图片／文件分享。Windows全局快捷采集、LAN编辑／删除／附件同步及持久冲突处理继续开发。
- 提醒依赖系统权限和平台运行状态，Windows正常退出后不能等同常驻后台服务。延后后的二次送达、休眠／重启、其他录音中断、Windows真实Toast动作／旧库，以及跨设备备份恢复仍有待验项目。
- 安全凭据由操作系统安全存储保护，事项数据库未做全库应用层加密；跨设备恢复不自动携带服务密钥。macOS／iOS、正式Windows签名及其他数据保护尾项按阶段台账继续推进。
