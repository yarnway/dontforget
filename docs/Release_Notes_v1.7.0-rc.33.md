# DontForget v1.7.0-rc.33

此版本为预发布候选，版本 `1.7.0+33`、数据库 schema 14，固定源码 `dbebd361ccbaa4a19ebe3914d5be41fc6c0fb68c`。

- 修复事项详情中修改分类、时间等字段后，灵动岛按钮未立即识别未保存修改的问题；恢复原值后按钮立即恢复可用。
- 保留圆弧录音交互：上滑后向左取消、向右转文字并编辑，直接松手保存语音；转写草稿需要明确点击发送。
- 保留学习卡片、输入剪贴板操作、明暗主题、非遮挡工具面板及受控实时活动。

静态分析、本地 1317 项 Flutter 和 126 项 Python 测试通过。云端七项作业成功，Flutter 1316 通过/1 项平台跳过，Python 125 通过/1 项平台跳过；五平台附件清单、版本与源码、七个包的摘要和大小已核对。

rc.33 已在 iPhone 15 Pro Max 完成完整签名升级、未保存修改门禁、灵动岛紧凑倒计时与展开、热点击正确事项、退出进程后到期、系统通知送达独立读回及合成事项取消。原有三条任务、五条媒体记录和五份媒体文件保持。Mac 的“全部”视图及 Cmd+K 工具导航通过。灵动岛冷点击、普通通知热冷点击、软键盘日文和真实录音手势仍有待验收项，尚不发布稳定版。

附件中的 iOS 包未签名，需自行开发或分发签名；macOS 包未公证，Android 为测试签名。这些构建不代表正式商店分发。后续 main 中新增的规划、用药、出门和便携备份功能不包含在此固定候选中。
