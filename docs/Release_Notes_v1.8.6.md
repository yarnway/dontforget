# DontForget v1.8.6 · Android / Windows / Linux

只读详情、明确编辑入口与学习计划改期，build75／schema17。

## 更新

- 点击事项、通知或关联任务先进入只读详情；标题和正文可复制，附件可预览。点击“修改”才进入编辑，不因浏览改变内容、日期、清单或关联。
- 编辑读取最新保存值，底部提供返回和保存；未保存文字离开前可继续、放弃或保存。未改内容直接保存不重复写入或重新排提醒，保存后返回更新后的详情。
- 兼容按年重复和已保存的情境模式；中英日文、明暗主题、窄屏、大字号和安全边距适配。
- 学习计划支持单计划／多选批量调整日期，逐批次预览；共享已学词条要求选择相关计划，防止误改其他计划。一次事务验证快照和进度，失败整体回滚。
- 保留学习次数、掌握度、暂停状态及附件；队列和七天概览同步使用新日期。完成、归档、回收站及暂不支持的重复批次不改期。
- 保留ARM64小包，无新增依赖或数据库迁移。

## 验收范围

- Android固定签名ARM64 APK／通用APK／AAB、Windows x64 Setup／Portable、Linux x64归档；Linux基线Ubuntu24.04，Windows未做Authenticode签名。
- 源码、自动化、候选构建、普通安装升级和真实设备分别记录，见[阶段台账](https://github.com/yarnway/dontforget/blob/main/docs/Next_Steps_2026-11-02.md)。编辑中的附件和关联仍按各自操作单独保存；返回时的草稿提示针对未保存表单。
- 动态学习预测、档案管理、图片分享／同步冲突继续；其他IME／机型、通知休眠与录音中断、Windows GUI、恢复故障、Apple设备／签名及商店仍待验。
